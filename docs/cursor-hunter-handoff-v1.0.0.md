## 사용자 확정과 이번 제안

약2시간 엔딩, 강한 인플레이션, 모든 해금 몬스터의 누적 출현, 대량 처치, 성장 후 보스 돌파를 유지한다. 최초는 커서를 겹쳐 좌클릭, 이동·홀드만으로는 공격하지 않는다. 자동화는 특성 해금. 보스 실패는 무보상, 파훼 성공은 추가 보상 예약, 실패는 시간 차감이다.

특성은 좌상단 Stat/Skill/Monster, 좌중단 보석, 우상단 요약 그래프, 중앙 팬·줌 트리, 하단 선택 상세다. 다른 가지를 배타적으로 잠그지 않는다. 자동은 v3 조건이며 트리플 구매와 독립이다.

Keep on Mining 공식 Steam 소개와 사용자 스크린샷에서 영구 성장, 넓은 연결 트리, 후속 자동화의 리듬을 참고했다. 직접 플레이 검증은 수행하지 않았다. 기존 클릭 전투를 유지하며 별도 광산·제작·랜덤 카드는 v1에 추가하지 않는다.

Windows x64·한국어/영어·마우스/키보드, Steam Cloud와 도전과제12개는 이번 제안이다. 사용자의 최종 승인으로 오인하지 않는다. 지원 범위 질문은 보냈으나 회신이 없는 상태에서 초안으로 작성했다.

## 밸런스 변경

완성 공격력·총비용·보스 HP는 v0.0.3 기준을 유지한다. 공격력 L5~9 다음 노드는5회, L10~29는10회 부분 강화로 나눠 매 구매마다 화력을 올린다. 비용 합계는 원래 노드 비용과 일치한다. 후반 마지막 강화의 고정 수입 가정상9~10분 대기를 약55~61초 단위로 나눴다. 실제 성장 중 수입이 증가하므로 엔딩 시간이 단축될 가능성은 플레이테스트에서 확인해야 한다.

## 검증과 남은 결정

48개 화면 경로 도달,118개 노드 선행 순환 없음, 독립 자동화, 분할 비용 합계와 피해 증가, PDF 내부 링크를 자동 검증했다. PDF64쪽 전체 렌더링 시각 검수 후 수정 페이지를 재검수했다. 이는 Unity 플레이테스트나 성능 테스트가 아니다.

출시 전 필수: 공격·범위·경제 우선3경로의 첫 엔딩110~130분, 초반 클릭 피로, 후반 물량·프레임·메모리, 저장 실패·중복 지급·Cloud 복구, 언어/UI 스케일을 실제 빌드로 검증한다. 최저사양·가격·출시일·지원 OS와 입력·최종 아트·크레딧·문의 주소는 확정이 필요하다. 코드 시스템의 존재를 추정하거나 문서 내용을 구현 완료로 표현하지 않는다.
