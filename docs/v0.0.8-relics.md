# v0.0.8 유물 드롭 및 효과

아래 확률은 해당 일반 몬스터를 **한 마리 처치할 때** 굴리는 각 유물의 기본 확률이다. 한 몬스터가 가진 유물 두 개가 모두 미획득 상태면 전체 기본 발견 확률은 3.5%다. 네잎클로버 보유 시 미획득 유물이 남은 몬스터의 전체 발견 확률에 1%p를 더한다. 하나가 발견되어도 다른 유물의 확률은 변하지 않는다. 처치 한 번에 최대 하나만 나오며, 이미 얻은 유물은 후보에서 제외한다. 보스 전용 유물 드롭은 없다.

전투에서 얻은 유물은 젬스톤처럼 좌측 하단에 아이콘이 수집된다. 전투 정산 뒤에는 중앙에 유물 원본 아이콘과 이름, 보유 후광 스프라이트를 보여주며 `확인`으로 발견 연출만 닫는다. 유물 보관소에서는 중앙 획득 애니메이션 대신 처음 상세를 열기 전까지 `New` 표시를 사용한다.

## 경험치 및 레벨

- 몬스터 01~10 처치 경험치: **1 / 1 / 2 / 2 / 3 / 3 / 4 / 7 / 7 / 9 XP**.
- 보스 1~20단계 경험치: **40 + 단계 × 10 XP** (50~240 XP, 20단계 누적 2,900 XP).
- 경험치는 전투 정산에 누적하고, 레벨업할 때 특성 카드를 지급한다. 25레벨 도달 시점과 실제 필드 개방 속도는 Unity 전투에서 확인한다.

## 필드 선택

레벨 1~4는 초원만 열려 있다. 레벨 5/10/15/20에서 필드 2~5가 차례로 열린다. `일반 전투`를 누른 뒤 열리는 화면에서 열린 필드 카드를 누르면 별도의 확인/출전 버튼 없이 즉시 출전한다. 선택 필드는 저장되며 다음 일반 전투에 적용된다.

| 필드 | 해금 레벨 | 젬스톤 보상 | 경험치 보상 |
|---:|---:|---:|---:|
| 초원 | 시작 시 | 기본 | 기본 |
| 속삭임 숲 | 5 | +10% | +5% |
| 수정 협곡 | 10 | +20% | +10% |
| 바람 고원 | 15 | +35% | +20% |
| 별빛 유적 | 20 | +50% | +30% |

보스 전투에는 필드 보너스를 적용하지 않는다.
