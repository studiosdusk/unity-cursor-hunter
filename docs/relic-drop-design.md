# 유물 효과와 몬스터 드롭 초안

작성일: 2026-10-21. 2026-11-10 업데이트: 20개 유물은 GameInformation v4 JSON에서 런 시작 `ProgressionCombatSnapshot`으로 전달된다. 소유 효과는 Combat 피해·기본 공격 주기·펫·스킬 범위/쿨타임·스폰 간격·시간·보상 처리에 적용한다. 일반 몬스터 처치 드롭과 정산 저장도 연결되어 있다. 실제 플레이·재실행 검수는 남아 있다.

## 드롭 규칙

각 몬스터에 연결된 미획득 유물마다 독립적인 기본 확률 `pᵢ`를 둔다. 처치 시 소유하지 않은 유물만 후보로 만들고, 먼저 후보 확률의 합 `P = Σpᵢ`로 드롭 여부를 한 번 굴린다. 성공하면 두 번째 굴림에서 각 유물의 가중치 `pᵢ`에 따라 하나를 고른다. 처치 1회에서는 최대 한 개만 획득한다. 실행은 `CombatRunController`의 별도 런 시드 난수열을 사용해 전투 치명타·젬 보너스 난수열에 영향을 주지 않는다.

이 방식에서 특정 미획득 유물 `i`가 나올 기본 확률은 `P × (pᵢ / P) = pᵢ`다. 다른 유물을 먼저 얻어도 남은 유물의 기본 확률은 올라가지 않는다. 네잎클로버를 보유하면 미획득 후보가 하나 이상 있는 처치에 전체 성공 확률만 1%p 추가한다. 이후 선택은 기존 `pᵢ` 비율을 유지한다. 예를 들어 같은 몬스터가 유물 A 5%, 유물 B 2%를 가진 경우, 기본 전체 드롭률은 7%다. 네잎클로버 보유 시 8%가 되며, 선택 비율은 5:2 그대로다. A를 얻은 뒤 B의 기본 드롭률은 2%로 유지된다.

후보 확률의 합이 100%를 넘는 설정은 자동으로 비례 축소하거나 100%로 자르지 않고 잘못된 설정으로 처리한다. 그래야 어떤 유물의 개별 확률도 설정값보다 바뀌지 않는다. 이미 모든 유물을 얻은 몬스터는 후보가 없어 유물을 주지 않는다. 일반 몬스터 처치당 지급 상한은 1개다.

## 유물 효과 및 출처

확률은 해당 몬스터 처치 1회당 각 유물의 고정 기본 확률이다. 보유 여부는 다른 유물의 확률을 바꾸지 않는다. 현재 기본 확률은 일반 후보 5%, 짝 유물 2%이며, 네잎클로버는 별도로 전체 발견 확률을 1%p 올린다. 도감에는 플레이어가 이해하기 쉬운 한 줄 효과를 표시한다.

## 런타임 JSON 전달 데이터

각 `information.relics[]` 정의에는 `id`, `owned`, `sourceMonsterId`, `dropChancePercent`, `effectId`, `effectValue`, `effectValue2`가 있다. 표시 이름·아이콘·설명은 현재 `RelicCollectionCatalog`의 표시 데이터가 담당한다. 테스트 도구의 획득 상태는 `owned`에 들어가며 런 시작 시 `ProgressionCombatSnapshot.Relics`로 복사된다. `RunCoordinator`가 보유한 효과만 집계하고 `CombatRunController`가 이번 런의 전투·보상 처리에서 사용한다. `relicDropRules`도 전달되지만, 처치 기반 드롭 굴림과 획득 저장은 아직 연결되지 않았다. Combat은 저장소를 직접 수정하지 않는다.

유물 드롭은 일반 필드의 일반 몬스터 처치에서만 발생한다. 런 결과 `RelicAwards`에 ID를 담고, App 정산이 재화와 한 번에 PlayerPrefs에 저장한다. 다음 런 시작 시 `owned`로 복원되며 효과가 적용된다. 런 중 획득된 유물은 현재 실행 중인 전투 수치에 소급 적용하지 않는다. 전투 중 드롭된 아이콘은 보석 수집 연출을 따라 좌측 하단 유물 줄로 날아와 추가된다. 테스트 도구의 획득/회수 작업도 저장 상태와 동일하게 바뀐다.

`effectId`는 다음 구현의 안정된 분기 키다. 퍼센트 효과 수치는 `effectValue=5`가 5%처럼 퍼센트 포인트로 저장되며, 초와 배수는 해당 단위를 그대로 쓴다. 크라켄의 눈은 `effectValue=50` 발동 확률, `effectValue2=30` 최대 체력 기준 퍼센트를 쓴다.

획득 상태를 반영한 뒤 후보 목록을 다시 계산할 때도 남은 개별 확률을 고정한다. 몬스터 보상·젬 보상·유물 드롭은 서로 다른 지급 항목이며, 유물 성공 시에도 같은 처치의 일반 보상은 정상 지급한다.
