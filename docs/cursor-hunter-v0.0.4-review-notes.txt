Cursor Hunter v0.0.4 문서 외 안내

1. 이번 반영 내용
- 젬스톤은 시작 시 가넷 한 종류만 노출한다.
- v1 최초 처치 시 토파즈, v2 시 자수정, v3 시 사파이어, v4 시 다이아몬드를 순서대로 해금한다.
- 잠긴 젬스톤은 초반 HUD, 보스 보상 미리보기, 특성 재화 목록에 이름·아이콘·수량을 표시하지 않는다.
- Main 최상위 메뉴에서는 보유 젬스톤을 제거하고, 실제 플레이와 연결되는 Field·보스·정산·특성 화면에서 해금된 종류만 보여준다.

2. 기획서 밖의 검토 메모
- Keep on Mining은 공식 Steam 소개에서 커서 중심 작업, 영구 성장, 연결형 성장 구조, 후속 자동화의 리듬을 확인하는 자료로 사용했다. 사용자 제공 트리 이미지는 특성 화면 배치의 시각 방향으로만 사용했다.
- v0.0.4의 약 2시간 엔딩 수치와 공격력·몬스터·보스 HP는 설계 기준값이다. 실제 플레이에서 공격 우선·범위 우선·재화 우선 경로의 소요 시간을 측정해 조정해야 한다.
- 후반 대량 몬스터와 자동 타격은 프레임 시간·메모리·숫자/파티클 가독성 측정이 필요하다.
- 저장 실패·중복 지급·Cloud 이동·언어/UI 배율·해상도 복귀는 실제 빌드에서 확인해야 한다.
- 가격, 출시일, 최저 사양, 최종 아트·음원·크레딧·지원 범위는 별도 제품 결정이다.

3. 문서 범위
- PDF에는 위 검토 메모와 외부 자료 설명을 넣지 않고, 게임 규칙·화면·수치·전환만 수록했다.
- 본 작업은 기획서와 PDF 생성물만 갱신했으며 Unity 게임 코드나 Steam 배포 파일은 변경하지 않았다.
