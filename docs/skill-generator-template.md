# 새 자동 스킬 구현 요청서

새 스킬을 만들 때 이 파일의 `【...】` 부분만 답으로 바꿔서 채팅에 보내 주세요. 문서 전체를 보내도 되고, **작성란**만 복사해 보내도 됩니다. 최소한 **스킬 이름, VFX 경로(없으면 `없음`), 공격 진행 순서, 생성 위치, 목표, 피해가 발생하는 순간**을 적어 주세요. 나머지 안내 문구를 그대로 두면 구현할 때 임시값을 추천합니다. 한 문장으로 설명하기 어려운 공격은 **공격 진행 순서**에 단계를 추가해 주세요.

- 수치를 아직 모르겠으면 `추천`이라고 쓰세요. 임시 기본값을 제안하고 컨트롤러에서 조절할 수 있게 구현합니다.
- 해당 요소가 없으면 `없음`이라고 쓰세요. 예: 즉시 공격의 지속 시간.
- 설계를 아직 결정하고 싶지 않으면 `미정`이라고 쓰세요. 코어 구현에 꼭 필요한 결정이면 먼저 확인하고, 그 외 항목은 기획서에 미정으로 남깁니다.
- VFX가 프로젝트에 있으면 `Assets/...` 경로를 적어 주세요. 사진만 있으면 사진을 첨부하고 에셋 이름이나 보이는 경로를 적어 주세요.

## 이미 적용할 공통 규칙

해금된 스킬은 커서 공격 여부와 관계없이 전투 중 자동 발동하며, 자기 쿨타임을 갖습니다. 일시정지에는 발동·수명·타격 시계가 멈춥니다. 스킬 피해는 전투의 공통 피해·처치·보상 경로를 사용하고, 종료된 런의 효과는 피해를 주지 않습니다. 컨트롤러 프리팹을 Main 씬의 `CombatManager` 아래에 두고, 기본 수치를 그 인스펙터에서 조절합니다. 에디터의 `Skill Acquired` 토글로 저장 상태를 바꾸지 않고 해금을 시험합니다. 월드 오브젝트가 필요하면 프로젝트 소유 프리팹으로 만들고 반복 사용 시 풀링합니다. **이 양식은 코어 구현용이며, 특성 업그레이드와 Editor Preview Level은 별도로 요청할 때만 다룹니다.**

이 문서의 빈칸은 스킬마다 달라지는 **게임 동작**을 정하기 위한 것입니다. 클래스 구조, 버퍼 크기, 풀 구현 방식 같은 내부 선택은 [자동 스킬 기획서](skill-design.md)에 맞춰 구현하면서 결정합니다. 공식 필드 범위는 아직 정하지 않았으므로 이 양식에서도 확정하지 않습니다.

## 작성란

### 1. 스킬 정체성

- 스킬 이름: 【 】
- 한 문장 설명: 【 】
- 사용하려는 VFX 프리팹 경로: 【 】
- 사용할 사운드 에셋 경로: 【없으면 `없음`】
- 스킬 ID가 이미 정해졌다면: 【없으면 `추천`】

### 2. 자동 발동

- 기본 재사용 대기시간: 【초 또는 `추천`】
- 전투 시작 후 첫 발동 시점: 【즉시 / 몇 초 후 / `추천`】
- 공격할 적이 없을 때: 【발동하고 쿨타임 소비 / 기다렸다가 발동 / `추천`】
- 일반전과 보스전의 차이: 【같음 / 차이를 설명 / `추천`】

### 3. 공격 진행 순서

스킬이 **어디에서 시작해 어떤 조건으로 다음 효과를 만들고 언제 피해를 주는지** 순서대로 적어 주세요. 커서 범위를 발사한 뒤 그 안에 들어온 적에게 다른 효과를 만드는 스킬처럼 여러 단계여도 됩니다.

1. 【첫 발동 때 일어나는 일】
2. 【대상을 찾거나 명중했을 때 일어나는 일. 없으면 `없음`】
3. 【후속 효과나 종료 동작. 없으면 `없음`】

### 4. 위치·대상·움직임

- 생성 또는 발사 기준 위치: 【필드 무작위 / 현재 커서 / 적 위치 / 고정 위치 / 직접 설명】
- 커서나 적의 위치를 쓰면 언제 확정하는지: 【발동 순간 / 계속 따라감 / 해당 없음 / `추천`】
- 목표 선택 방식: 【범위에 들어온 모든 적 / 가장 가까운 적 / 무작위 적 / 직접 설명】
- 이동 방식: 【없음 / 방향·속도·추적·경로 변경 방식을 설명 / `추천`】
- 같은 적에게 여러 효과가 겹칠 때: 【각각 적용 / 한 번만 적용 / 직접 설명 / `추천`】

### 5. 타격과 수명

- 피해가 발생하는 순간: 【생성 직후 / 닿을 때 / 범위 진입 시 / 일정 간격마다 / 직접 설명】
- 같은 적을 다시 때릴 수 있는 간격: 【초 / 한 번만 / `추천`】
- 기본 피해량: 【기본 공격력의 몇 배 / 고정값 / 피해 없음 / `추천`】
- 히트 영역: 【모양·대략적 크기 / 프리팹에서 직접 조절 / 영역 없음 / `추천`】
- 효과 지속 시간: 【초 / 즉시 종료 / `추천`】
- 끝날 때의 연출: 【즉시 사라짐 / 축소 / 페이드 / 별도 VFX / `추천`】

### 6. 인스펙터와 제작물

- 컨트롤러에서 직접 조절하고 싶은 값: 【예: 개수, 이동 속도, 피해 배율, 타격 간격 / `위에 쓴 수치 전부`】
- 내가 나중에 손볼 프리팹 부분: 【예: VFX 크기, 히트박스, 색, 사운드 / `추천`】
- 한 번에 만들 개수와 예상 최대 동시 개수: 【각각 숫자 / 오브젝트 없음 / `추천`】

### 7. 특별 규칙 또는 기대 장면

- 위 항목에 없는 상태 효과·연쇄 공격·특별한 조건: 【없음 / 설명】
- 플레이 중 꼭 확인하고 싶은 장면: 【예: 적 3마리가 범위에 들어오면 모두 맞는다 / `기본 검증으로 충분`】

## 전달할 때 함께 알려주면 좋은 것

- VFX가 보이는 사진 또는 프리팹 경로
- 지금 떠올린 움직임이나 타격감의 참고 이미지·영상
- 이미 수정해 둔 Main 씬 인스펙터 값이나 프리팹 변경 사항

작성란을 받으면 먼저 스킬의 공격 과정을 정리하고, `추천`으로 남긴 임시 수치를 표시한 뒤 코어를 구현합니다. 필수 동작이 `미정`이면 필요한 질문만 먼저 드립니다. 구현 후에는 Main 씬의 컨트롤러 사용법과 검증 결과를 알려드립니다.
