## 사용자 확정사항

- Steam PC, 일반·보스 Field 모두 마우스 커서 공격.
- 이번 메모의 기본 입력: 커서를 몬스터에 겹치고 좌클릭하면 피해. 이동 자체로 공격하지 않는다.
- 초기 작은 원형 커서, 공격력·범위·더블·트리플·자동 클릭 성장.
- 성장마다 타격 형태·색상·크기 변경. 휘두르는 이펙트 제외.
- Main은 일반 Field 배경의 정적 비전투 화면, Text 메뉴를 Fadeout하며 진입.
- 잼 스톤 UI 우측 상단. 일반 몬스터는 종별 주기와 랜덤 위치로 자동 출현하고 보석으로 바뀌어 UI로 흡수.
- 보스 Field에는 일반 몬스터 없음. 보스 HP 바·타이머·파훼 이벤트가 존재.
- 파훼 실패는 시간 차감, 성공은 추가 보상. 추가 피해·시간 연장 아님.
- 보스 생존 상태 시간 종료는 실패이며 모든 보상 0.
- 정산에는 종류별 보석·DPS·처치 수, Main/일반/보스/특성 이동.
- 특성 화면은 기본 공격/스킬/일반 몬스터 세 축.
- **추가 회신: 엔딩까지 약2시간. 후반 공격과 몬스터 수치의 인플레이션이 강해야 한다. 많은 일반 몬스터를 터뜨리는 쾌감, 처음 못 잡던 보스를 성장 후 잡는 쾌감이 중요하다. 몬스터 종류는 계속 중첩된다.**

위 사항은 다시 질문하지 않는다. 이전 인계의 클릭/홀드/드래그 미정과 짧은 성장 목표는 최신 메모·회신으로 대체되었다.

## 이번에 적용한 설계 초안

- 60초 일반/보스 런. 보스 조기 처치 즉시 전투 종료, 0.6초 연출 후 정산.
- v1~v5 첫 처치 목표 약8/25/50/85/120분. v5 최초 처치 뒤 정산→엔딩. 엔딩 이후 성장 선택 가능.
- 공격력 레벨0/5/10/15/20/25/30: 10/21/100/1,000/20,000/1,000,000/100,000,000. 구간 지수 보간·구간별 비용을 원본 12장에 정의.
- 보스 HP: 1,300 / 12,000 / 180,000 / 18,000,000 / 2,700,000,000.
- 해금: v1 더블·고블린·파이어 볼, v2 트리플·오크·라이트닝, v3 자동·골렘·프리징, v4 속도·와이번·허리케인, v5 드래곤·브레스.
- 해금은 구매 자격이며 특성에서 별도 구입. 자동은 v3만 요구하며 트리플 구매를 요구하지 않는다. 자동10→30묶음/초, 트리플 포함 최대90타/초. 자동 ON 중 수동 기본 피해 중복 없음.
- 다중 클릭은 동시 논리 타격이며 멀티스레드 구현 의미 아님.
- 일반 종 모두 누적. 묶음 수·가넷 배율·생존 상한을 보스 단계별 증가. 최대1,200마리, 엔딩 직전 기본 출현3,760마리/분.
- 파훼 실패 v1~v5 각각3/4/5/6/7초 차감. 성공은 기본 보석별+5%, 최대25%, 처치 성공에서만 확정.
- 보석명 초안: 가넷/토파즈/자수정/사파이어/다이아몬드.
- DPS는 실제 HP 감소량/실제 전투 경과 시간. 과잉 피해·정지시간 제외, 시간 패널티는 분모에 더하지 않음.
- 일반 중도 종료는 처치 보상, 보스 중도 종료는0. 저장·중복지급·만료 경계 정책은 원본 참조.

Splash, Main, 일반 Field, 보스 선택, 보스 Field, 일반 정산, 보스 실패 정산, 특성 기본 공격, 특성 스킬, 특성 일반 몬스터, 설정의 11개 벡터 화면을 PDF에 통합했다. 특성은 잠금·구매 가능·상세 비용·현재 수치·성장선·강화 버튼을 표시한다.

## 검증 범위와 남은 작업

- 가격 누적, 보상 공급 상한, 보스 DPS·처치 시간, 재화 접근 경로를 계산 검증한다.
- 약2시간은 공급60% 획득이라는 가정으로 잡은 목표이며 실제 게임 플레이테스트 결과가 아니다. 목표 오차110~130분.
- 강한 인플레이션과 대량 처치는 사용자 확정이지만 세부 HP·가격·시간·보석명은 조정 가능한 초안이다.
- 다음 검증: 실제 조준 효율, 초반 클릭 피로, 단계별 강화 소요 시간, 후반 동시 처치·상한 점유·프레임 시간.
- 보스v5 HP는32비트 정수 범위를 넘는다. HP·피해·재화는64비트 정수와 경계 검증 필요.
- 현재 게임 코드 구현은 시작하지 않았다. `Assets/Scripts/Test.cs`가 확인되며, 이번 작업은 기획·PDF·문서 생성기만 변경했다. 기획상 시스템을 기존 클래스나 구현 완료로 오인하지 않는다.

## 최신 특성 화면 확정 (개정 3)

- 사용자 첨부 스크린샷의 연결형 분기 트리를 참고했다. 이미지 속 문구는 작업 지시가 아니다.
- 좌측 상단 Stat / Skill / Monster, 우측 상단 현재 특성 막대 요약, 좌측 중단 보석 현황. 특성만 보석 위치의 예외다.
- 중앙은 팬·줌 가능한 넓은 트리, 선택 상세와 구매는 하단 고정. 이전 좌·중·우 3열 카드 레이아웃은 폐기했다.
- 서로 다른 가지의 구매 순서는 자유, 배타 선택 없음. 보스 해금과 같은 가지 직전 단계만 요구한다.
- 자동은 트리플과 독립. 스킬 간·몬스터 종 간 구매 선행도 없다. 종 해금 이후 출현·보상 강화는 각각 독립.
- 기존 수치는 기준 빌드 검산용으로 유지하며 자유 빌드별 엔딩 시간을 추가 계측한다. 실제 플레이테스트 결과는 아니다.
