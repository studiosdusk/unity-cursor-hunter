# v0.0.4 PDF 시각 검수 기록

- 대상: `output/pdf/cursor-hunter-game-design-v0.0.4.pdf`
- 렌더링 페이지: 61쪽
- 화면 상태: 48개
- 검수 방법: Poppler로 61쪽을 PNG로 렌더링한 뒤 4쪽 단위 contact sheet 16장을 확인

## 확인한 화면

- Main·Splash·설정·기록·엔딩에는 젬스톤 HUD가 없다.
- 게임 시작·튜토리얼·일반 필드 초기 상태에는 가넷 한 칸만 표시된다.
- 보스 최초 처치 진행에 따라 토파즈·자수정·사파이어·다이아몬드가 순서대로 추가된다.
- 특성 화면에는 해금된 젬스톤만 표시되고, 잠긴 젬스톤의 이름·아이콘·0 수량이 노출되지 않는다.
- 보스 선택·보상 미리보기는 잠긴 보상을 이름 대신 상태 문구로 표시한다.
- 일반 필드·보스 필드·정산·특성 화면의 연결 흐름과 48개 화면 링크를 확인했다.

## 결과

모든 페이지에서 텍스트·카드·연결선·젬스톤 HUD가 페이지 경계를 넘지 않았고, 현재 생성본에서 눈에 띄는 잘림이나 겹침은 확인되지 않았다.
