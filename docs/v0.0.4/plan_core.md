# CURSOR HUNTER · v0.0.4
## 세부 기획 · 젬스톤 진행 · 전체 화면 설계

대상: Unity 2D / Steam PC / 마우스 커서 액션 성장 게임
목표: 약 2시간 동안 커서 조작, 영구 특성 성장, 보스 돌파, v5 엔딩을 경험한다.

## 00. 게임 개요와 핵심 루프

플레이어는 화면의 몬스터 위로 커서를 옮긴 뒤 좌클릭하여 공격한다. 최초에는 작은 원형 커서와 단일 타격으로 시작한다. 보스를 처치할수록 새로운 몬스터·스킬·젬스톤이 열리고, 특성 트리에서 원하는 가지를 골라 공격 범위·타격 수·자동화를 성장시킨다.

```text
게임 실행 → 첫 설정 → 무료 연습 → 60초 일반 Field
→ 일반 정산 → 특성 구매 → 일반 Field 반복
→ 보스 선택 → 60초 보스 Field → 파훼 성공/실패
→ 보스 정산 → 새 해금 → 다음 보스
→ v5 최초 처치 → 엔딩·크레딧 → 엔딩 이후 자유 성장
```

일반 Field에서는 해금한 모든 몬스터가 주기와 무작위 위치에 따라 함께 등장한다. 몬스터가 죽으면 해당 보상이 런 기록에 즉시 들어가고, 젬스톤 형체가 HUD 슬롯으로 0.35~0.65초 동안 이동한다. 이동 연출이 끝나기 전에 화면을 바꾸어도 지급 수량은 변하지 않는다.

## 01. 화면 기준과 공통 UI

- 전투 기준 해상도는 1920×1080, 최소 지원 레이아웃은 1280×720, 모든 화면은 16:9 전투 영역을 유지한다.
- 전투 외곽 32px, 상단 HUD 160px, 하단 안내 96px은 몬스터 생성 영역에서 제외한다.
- 일반·보스 Field는 타이머를 좌측 상단, 젬스톤 HUD를 우측 상단, 보스 HP를 그 아래 두 번째 행에 둔다.
- 특성 화면은 좌측 상단 `Stat / Skill / Monster` 탭, 좌측 중단 젬스톤 보유 목록, 우측 상단 현재 특성 막대 요약, 중앙 팬·줌 트리, 하단 선택 상세 영역을 고정한다.
- Main은 일반 Field 배경을 사용하는 정적 메뉴다. 중앙 메뉴는 텍스트와 hover 밑줄로 표시하며, 전투 HUD를 그리지 않는다.
- 텍스트 버튼의 실제 클릭 영역은 최소 160×48px이다. hover 밑줄, 키보드 포커스 테두리, 잠금 사유를 함께 표시한다.
- 시스템 팝업·메뉴·보스 파훼 표식·전투 순서로 입력 우선순위를 둔다. 팝업을 닫은 클릭은 다음 화면의 공격으로 전달하지 않는다.
- ESC, 창 포커스 상실, Steam Overlay는 전투·타이머·스킬·파훼를 함께 멈춘다. `계속`을 새로 입력해야 재개한다.

## 02. 젬스톤 해금과 표시

### 해금 순서

| 진행 상태 | 표시·획득 가능한 젬스톤 | 해금 사건 |
| --- | --- | --- |
| 게임 시작 | 가넷 | 최초 저장 생성 |
| v1 격파 후 | 가넷, 토파즈 | v1 슬라임 킹 최초 처치 |
| v2 격파 후 | 가넷, 토파즈, 자수정 | v2 고블린 족장 최초 처치 |
| v3 격파 후 | 가넷, 토파즈, 자수정, 사파이어 | v3 오크 워로드 최초 처치 |
| v4 격파 후 | 가넷, 토파즈, 자수정, 사파이어, 다이아몬드 | v4 수정 골렘 최초 처치 |
| v5 격파 후 | 위 5종 유지 | v5는 엔딩과 최종 성장 해금 |

가넷은 시작 특성·공격력·일반 보상의 기본 재화다. 토파즈는 범위·다중 타격, 자수정은 스킬·자동 클릭, 사파이어는 자동 속도와 후반 해금, 다이아몬드는 드래곤 브레스와 최종 성장에 사용한다.

### 표시 규칙

1. 새 게임과 무료 연습에서는 가넷 슬롯 하나만 렌더링한다. 잠긴 젬스톤의 이름·아이콘·0 수량·빈 슬롯을 그리지 않는다.
2. 보스를 최초 처치하는 정산 저장이 끝난 순간 다음 젬스톤 슬롯을 추가한다. 새 슬롯은 0에서 시작하며 이전 런에 소급하여 보상을 만들지 않는다.
3. 일반 Field, 보스 선택, 보스 Field, 일반·보스 정산, 특성 화면은 현재 해금된 젬스톤만 보여준다. 슬롯은 항상 우측 또는 좌측 목록의 안쪽부터 채운다.
4. Main 최상위 메뉴, Splash, 첫 설정, 일시정지, 설정, 기록, 저장·복구 팝업, 엔딩·크레딧에는 젬스톤 보유 HUD를 두지 않는다.
5. 보스 선택에서 아직 잠긴 보스의 보상은 `잠긴 보상`으로 표시한다. 해금되지 않은 젬스톤의 명칭·수량을 미리 노출하지 않는다.
6. 특성 구매 상세는 필요한 재화가 해금된 경우에만 이름과 수량을 표시한다. 잠긴 재화는 보스 조건과 `새 젬스톤 해금` 안내로 표현한다.
7. 젬스톤 형체가 HUD로 이동하는 연출은 읽기 위한 시각 피드백이며, 런 보상·저장·정산의 지급 시점은 몬스터 사망 시점이다.

### 젬스톤 UI

전투·보스 선택·정산 HUD는 우측 상단에 해금된 종류를 오른쪽으로 정렬한다. 각 슬롯은 젬스톤 색상·이름·보유 수량·이번 판 증감을 표시한다. 특성 화면은 같은 목록을 좌측 중단 세로 카드로 표시한다. 수량은 999,999까지 그대로 표시하고 그 이상은 축약 표기와 툴팁의 정확한 정수를 함께 사용한다.

## 03. 커서 공격과 전투 종료

- 최초 공격력 A=10, 커서 반경 R=18px, 좌클릭 누름 1회가 한 공격 묶음이다. 커서와 몬스터 판정 원이 겹친 살아 있는 적 모두에게 피해를 준다.
- 이동·홀드만으로는 공격하지 않는다. 수동 공격은 초당 최대 8묶음, 기준 조작 속도는 초당 2클릭이다.
- 더블·트리플은 같은 대상 목록에 같은 시각 2/3회 타격한다. 첫 타격으로 죽은 대상의 남은 타격은 소멸하고 다른 대상에 전달하지 않는다.
- 자동 클릭은 v3 해금 후 특성에서 구매한다. 10→15→20→25→30묶음/초로 성장하며 자동 OFF에서는 수동 공격으로 돌아온다. 자동 중 수동 기본 공격을 추가로 중복 처리하지 않는다.
- 일반 Field와 보스 Field의 기본 제한 시간은 60초다. 정확히 만료한 시각의 공격·생성·파훼는 무효이며, HP가 0이 된 시각에는 즉시 성공 처리를 시작한다.
- 일반 Field 시간 종료는 생존 적을 보상 없이 제거하고 확정 처치 보상을 지급한다. 보스 시간 초과와 중도 포기는 기본·파훼 보상 모두 0이다.
- 실측 DPS는 실제 HP 감소량을 정지 시간을 뺀 전투 경과 시간으로 나눈다. 과잉 피해는 제외하고 스킬 피해는 포함한다.

## 04. 일반 Field

- 슬라임은 시작부터 등장한다. 이후 구매한 종은 고유 주기로 계속 함께 등장하며 교체·비활성화하지 않는다.
- t=0에 첫 무리를 생성하고 t=60에는 생성하지 않는다. 무리 중심은 HUD를 제외한 영역에서 무작위로 고르며 80px 안에 배치한다.
- 상단 160px·하단 96px·좌우 32px을 생성 금지 영역으로 둔다. 위치는 최대 8회 탐색하며 실패한 개체는 건너뛴다. 생존 상한을 넘는 생성은 누적하지 않는다.
- 종별 생성 기회는 라운드로빈으로 순환한다. 몬스터끼리 겹침은 허용하고, 종별 실루엣·색상·피격 이펙트로 구분한다.
- 피격 HP 바는 1초 표시한다. 처치 시 종별 보상 수량을 런 기록에 더하고, 해금된 젬스톤 형체를 해당 HUD 슬롯으로 보낸다.
- 남은 10초부터 타이머·경고음을 강조한다. 0초에 전투·생성을 멈추고 생존 적을 Fadeout한 뒤 0.4초 후 일반 정산으로 이동한다.

## 05. 보스 Field와 파훼

보스 Field에는 일반 몬스터가 없다. 보스 HP 바는 화면 상단에 가로로 길게 표시하며, 보스의 현재 HP·남은 시간·예약 보너스를 동시에 보여준다. 기본 공격과 스킬은 보스에게 피해를 주지만 자동 공격이나 스킬이 파훼 표식을 대신 처리하지 않는다.

| 보스 | HP | 예고 / 입력 | 실패 시 시간 차감 | 최초 처치 해금 |
| --- | ---: | --- | ---: | --- |
| v1 슬라임 킹 | 1,300 | 표식 1개 / 2.0초 | 3초 | 더블·고블린·파이어 볼·토파즈 |
| v2 고블린 족장 | 12,000 | 표식 2개 순서 / 2.0초 | 4초 | 트리플·오크·라이트닝·자수정 |
| v3 오크 워로드 | 180,000 | 표식 2개 순서 / 1.8초 | 5초 | 자동·골렘·프리징·사파이어 |
| v4 수정 골렘 | 18,000,000 | 표식 3개 순서 / 1.8초 | 6초 | 자동 속도·와이번·허리케인·다이아몬드 |
| v5 고대 드래곤 | 2,700,000,000 | 표식 3개 순서 / 1.6초 | 7초 | 드래곤·드래곤 브레스·L30 |

예고 중에는 외곽 윤곽만 표시하고, 입력 창에는 번호·닫히는 링·남은 시간을 표시한다. 번호를 순서대로 좌클릭하면 이벤트 1회 성공, 잘못된 클릭은 진행하지 않으며 창 종료 시 1회 실패한다. 성공할 때마다 처치 시 보너스 5%를 예약하고 최대 25%까지 누적한다. 실패는 남은 시간을 차감하며 보너스는 유지한다. 보스가 먼저 죽으면 진행 중 파훼 이벤트를 취소하고 성공 정산으로 이동한다.

## 06. 특성 화면과 자유 분기

Stat·Skill·Monster 탭은 항상 좌측 상단에 고정한다. 트리 캔버스만 팬·줌하고 탭·젬스톤·요약·하단 상세는 움직이지 않는다. 빈 공간 드래그와 중클릭으로 이동하고 휠 확대 범위는 60~160%다. 노드에서 6px 이상 움직인 입력은 탐색으로 처리한다.

공통 시작점은 무료다. 서로 다른 가지 사이의 선행 조건은 없다. 플레이어는 공격력·범위·다중 타격·자동화·각 스킬·각 몬스터를 원하는 순서로 구매한다. 같은 가지의 직전 단계와 보스 최초 처치 조건만 구매 조건으로 사용한다. 자동은 v3 처치만 요구하고 트리플 구매를 요구하지 않는다.

노드 상태는 완료, 구매 가능, 재화 부족, 선행 잠금, 보스 잠금, MAX를 아이콘·테두리·문장으로 구분한다. 노드 선택은 구매가 아니며, 하단 상세에서 `현재 효과 → 다음 효과`, 필요한 젬스톤, 부족 수량, 구매 횟수를 보여준다. 공격력 L5~9는 노드당 5회, L10~29는 노드당 10회 부분 강화로 나누며 각 구매마다 피해량을 올린다.

## 07. 성장·인플레이션 기준

### 공격력

| 완성 레벨 | 공격력 | 다음 구간 비용 계수 | 부분 강화 |
| ---: | ---: | --- | ---: |
| L0 | 10 | 30×1.18^L | 1 |
| L5 | 21 | 2,000×1.35^(L-5) | 5 |
| L10 | 100 | 80,000×1.35^(L-10) | 10 |
| L15 | 1,000 | 5,000,000×1.35^(L-15) | 10 |
| L20 | 20,000 | 200,000,000×1.35^(L-20) | 10 |
| L25 | 1,000,000 | 5,000,000,000×1.35^(L-25) | 10 |
| L30 | 100,000,000 | 최종 선택 성장 | - |

부분 강화 횟수를 s, 현재 진행을 q라 할 때 연속 레벨은 u=L+q/s다. 다음 완성 노드 비용 C를 `divmod(C,s)`로 나누고 나머지 횟수에 1가넷을 더해 합계 C를 보존한다. q=s가 되면 L을 1 올리고 q를 0으로 정규화한다.

### 일반 몬스터와 물량

| 종 | HP | 기본 주기 | 기본 보상 | 등장 보스 |
| --- | ---: | ---: | --- | --- |
| 슬라임 | 20 | 1.5초 | 가넷 3 | 시작 |
| 고블린 | 80 | 3초 | 가넷 7 + 토파즈 1 | v1 |
| 오크 | 800 | 4초 | 가넷 15 + 자수정 1 | v2 |
| 골렘 | 12,000 | 5초 | 가넷 30 + 사파이어 1 | v3 |
| 와이번 | 600,000 | 6초 | 가넷 60 + 사파이어 2 | v4 |
| 드래곤 | 30,000,000 | 10초 | 가넷 140 + 다이아몬드 1 | v5 |

최고 보스 진행도에 따라 묶음 수 배율은 1/2/3/5/8/10, 가넷 배율은 1/2/10/100/1,000/5,000, 생존 상한은 80/180/350/600/900/1,200으로 적용한다. 해금한 낮은 종도 후반에 계속 등장해 화면을 빠르게 채우는 역할을 한다.

### 스킬·타격 연출

파이어 볼, 라이트닝 볼트, 프리징, 허리케인, 드래곤 브레스는 각각 독립 구매 가지다. 스킬 피해는 기본 공격력 A를 기준으로 하며, 스킬이 파훼를 처리하지 않는다. 성장 단계마다 타격 형태·색상·크기를 바꾼다. 초기 흰 점, 더블 황금 이중 링, 트리플 보라 삼각 파편, 자동 청색 맥동 링, v5 흰 결정·화염 점을 사용한다. 휘두르는 궤적과 검기는 사용하지 않는다.

## 08. 정산·엔딩·설정

일반 정산은 젬스톤 종류별 이번 판 수량·최종 지급량, 종별 처치 수, 실측 DPS, 전투 시간, 다음 목적지를 표시한다. 보스 성공 정산은 기본 보상과 파훼 보너스를 분리하고 최초 처치 해금과 새 젬스톤 슬롯을 함께 보여준다. 보스 실패 정산은 보상 0, 남은 HP, 실패 횟수와 차감 시간, 다음 성장 버튼을 표시한다.

v5 최초 처치 후 엔딩 플래그를 저장하고 평원이 회복되는 20초 내외 연출과 크레딧을 실행한다. 엔딩 후 Main에서는 일반 Field, 보스 반복, 특성, 기록, 엔딩 다시 보기를 계속 제공한다. 엔딩 이후의 L30·드래곤·브레스는 선택 성장이다.

설정은 오디오, 화면, 입력·가독성, 데이터 탭으로 구성한다. 해상도·UI 배율·효과 강도·화면 흔들림·자동 단축키·언어·저장 복구·초기화를 제공한다. 전투 진행과 보스 해금은 로컬 저장과 백업 3세대에 기록하고, 구매·정산은 한 번만 지급되도록 정산 ID를 사용한다.

## 09. 전체 상태 목록

S01~S48은 최초 실행, 일반 Field, 보스, 특성, 설정, 저장 오류, 엔딩을 하나의 화면 상태 카탈로그로 정의한다. 각 상태 페이지는 진입 조건, 표시 정보, 행동, 전환, 예외·복귀를 포함한다. 화면 아래 이동 링크는 문서 내 탐색용으로 사용한다.
