# 2026-10-30 · 온보딩·성장·전투 통합 검증

대상: `ui-onboarding-balance`, Unity **6000.3.13f1**, `App/Scenes/Main.unity`.

자동 검증은 작업 폴더의 Assets/Packages/ProjectSettings/Library를 복사하고 회사·제품 이름을 분리한 격리 프로젝트에서 실행했다. 원본 프로필의 구매·재화·초기화는 수행하지 않았다. 실제 작업 폴더의 Unity에서는 이전 Play를 종료해 재컴파일한 뒤 메인 안내와 마우스 Trait 진입을 확인하고 편집 모드로 돌아왔다.

검증 당시 결과 XML·로그·PNG를 임시 폴더에 저장해 확인했으며, 검증 요약을 이 문서에 남긴 뒤 디스크 공간을 회수하기 위해 원시 결과와 격리 프로젝트 사본을 삭제했다. EditMode 181개와 PlayMode 52개로 중복을 제외한 **233개 Unity 테스트**가 통과했다. 그래픽 없는 실행에서 RenderTexture 기반 배치 검증을 시도하면 에디터가 충돌할 수 있어 해당 테스트는 GPU 실행을 요구하도록 명시했고, 최종 전체 PlayMode는 GPU 환경에서 모두 통과했다.

밸런스 기본값 읽기 검증 중 Unity가 빈 프리뷰 씬에 대해 AudioListener 부재 정보 로그를 출력한다. 실제 Main의 리스너·런 ID·스탯·시간·씬 원문은 검증에서 유지됐고, 테스트의 일반 정보 로그 금지 조건을 제거했다. 오류·예외에 대한 UnityTest 기본 실패 판정은 유지한다.

## 이번 검증에서 수정한 문제

- 기존 저장에 새 온보딩 구매 목록 전체를 요구하던 전투 진입 조건을 분리했다.
- 전투 결과의 강화 버튼이 로비를 거치던 경로를 특성 화면 직행으로 바꾸고 문구도 `특성 강화`로 맞췄다.
- 화면 수명주기에 맞춰 비전투 BGM을 정지·재개하도록 했다.
- 시작점의 `CORE`와 `시작점` 글자가 겹치던 중복 표기를 제거했다. TMP의 오래된 줄바꿈 API 경고도 갱신했다.
- 저장 v5 백업 키, 현재 22분류/89노드·밸런스 수치, 피해 함수 인자, 명시적 수동 스테이지 경로에 맞춰 오래된 테스트를 갱신했다.

## 남은 범위

1. **실제 보스전:** Main은 일반 필드 런만 생성한다. 실제 보스전 시작·보스 처치 결과가 연결되기 전에는 테스트 도구로 단계를 설정해야 한다.
2. **유물 실제 드롭·영속 저장:** 정의·개별 확률·같은 세션의 소유 상태/효과는 있지만 처치 드롭 굴림과 획득 ID 저장은 미구현이다. 다음 Play에서 테스트 소유 상태를 복구하지 않는다.
3. **체감 검수:** 장기 경제 곡선·공격 간격의 투자 가치·효과음/BGM 최종 음량·실제 마우스 관성·긴 툴팁 탐색은 별도로 남긴다.
4. 이번 검증은 Editor PlayMode 기준이다. 독립 플레이어 빌드는 실행하지 않았다.

미결 항목은 루트 `plans.md`와 `checkList.md`에서 관리한다. 이 문서는 검증 기록이며 미결 트래커에는 완료 이력을 중복 보관하지 않는다.
