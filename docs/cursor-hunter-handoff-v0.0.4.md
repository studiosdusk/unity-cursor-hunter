## 젬스톤 규칙

게임 시작과 무료 연습에는 가넷만 보인다. v1 최초 처치 후 토파즈, v2 최초 처치 후 자수정, v3 최초 처치 후 사파이어, v4 최초 처치 후 다이아몬드 슬롯을 추가한다. 잠긴 젬스톤은 HUD·보스 보상 미리보기·특성 재화 목록에 이름과 아이콘을 표시하지 않는다.

일반 Field, 보스 선택·Field, 정산, 특성 화면은 현재 해금된 젬스톤만 표시한다. Main 최상위 메뉴, Splash, 첫 설정, 일시정지, 설정, 기록, 저장·복구 팝업, 엔딩·크레딧에는 젬스톤 보유 HUD를 표시하지 않는다.

## 성장과 화면

커서 겹침 후 좌클릭 공격, 이동·홀드 무피해, 60초 일반·보스 런, 보스 파훼 성공 보너스·실패 시간 차감·실패 무보상 규칙을 유지한다. Stat·Skill·Monster는 좌상단 탭, 젬스톤은 특성 좌측 중단, 특성 요약은 우측 상단, 자유 분기 트리는 중앙, 노드 상세는 하단에 둔다. 서로 다른 가지는 독립이며 같은 가지 직전 단계와 보스 조건만 선행으로 사용한다.

공격력 후반 노드는 부분 강화로 나누고 총비용·완성 공격력 기준은 유지한다. 일반 몬스터 종은 해금 후 계속 누적 출현하며 v5 최초 처치가 엔딩으로 이어진다.

이 문서는 기획 자료이며 Unity 런타임 구현을 의미하지 않는다. 생성 명령과 검산 범위는 README에 기록한다.
