# 연구 노드 만들기

아래 양식을 복사해 빈칸을 채운 뒤 AI에게 보내주세요. 잘 모르는 항목은 비워 둬도 됩니다.

## 요청 양식

```text
아래 내용으로 연구 노드 SO를 만들어줘.
이 프로젝트의 docs/collaboration/research-node-ai-template.md도 참고해줘.

연구 이름:
툴팁 설명:
무엇이 바뀌나요?:
아이콘: 기존 에셋에서 찾아줘

레벨별 효과:
- 1레벨:
- 2레벨:
- 3레벨:

맵에도 배치할까요?: 아니요
```

레벨이 더 필요하면 줄을 추가하고, 적게 필요하면 지워주세요. **각 레벨에서 추가로 늘어나는 효과**를 적습니다. 구매하지 않은 0레벨에는 연구 효과가 없습니다.

## 작성 예시

```text
아래 내용으로 연구 노드 SO를 만들어줘.
이 프로젝트의 docs/collaboration/research-node-ai-template.md도 참고해줘.

연구 이름: 중급 공격력 연구
툴팁 설명: 기본 공격 피해 증가
무엇이 바뀌나요?: 커서의 기본 공격력이 올라가요.
아이콘: 검 모양으로 기존 에셋에서 찾아줘

레벨별 효과:
- 1레벨: 공격력 +3
- 2레벨: 공격력 +3
- 3레벨: 공격력 +3

맵에도 배치할까요?: 아니요
```

이 경우 3레벨의 효과는 공격력 **+9**입니다. 각 레벨의 수치를 모두 더합니다. 예시와 같은 연구가 이미 있다면 AI가 기존 노드를 확인하고 알려주도록 합니다.

## 맵에 바로 배치하고 싶다면

양식의 마지막 줄을 아래처럼 바꿔주세요. 비용은 맵 에디터에서 나중에 정해도 됩니다.

```text
맵에도 배치할까요?: 예
맵 버전:
위치: 원하는 위치 또는 좌표
선행 노드: 이 노드를 열기 위해 먼저 구매해야 하는 연구
레벨별 비용:
- 1레벨: 가넷 100
- 2레벨: 토파즈 200
- 3레벨: 자수정 300
```

선행 노드는 **1레벨 이상 구매**하면 조건을 만족합니다. 비용에는 가넷, 토파즈, 자수정, 사파이어, 다이아몬드, 드래곤 스톤을 사용할 수 있습니다. 같은 연구 SO를 여러 곳에 배치해도 비용은 각각 다르게 설정할 수 있습니다.

## AI 참고 사항

- 먼저 현재 연구 SO 구조와 실제 게임의 스탯·스킬·몬스터를 확인한다. 기존 노드와 중복되거나 요청이 모호하면 이를 알리고, 지원하지 않는 효과를 비슷한 효과로 임의 변경하지 않는다.
- SO에 표시 정보와 레벨별 효과를 넣는다. 고유 `stableId`와 텍스트 키를 사용하고 기존 ID를 다른 효과에 재사용하지 않는다.
- 한국어 제목과 효과 설명은 `Assets/CursorHunter/Data/Authoring/ResearchText.xlsx`에 추가하고 Unity Localization 반영을 검증한다. 다른 언어는 요청이 없다면 비워 둔다. 퍼센트는 소수 둘째 자리까지 표시한다.
- 아이콘은 기존 게임 에셋을 사용한다. 맵 배치를 요청받지 않았다면 기존 맵과 씬은 수정하지 않는다. 배치할 때는 별도의 `placementId`를 사용하고 비용·위치·선행 조건을 맵에 설정한다. SO의 비용은 레거시 호환용이다.
- 기획자가 적은 각 레벨의 효과는 해당 레벨에서 **추가되는 값**이다. SO에도 각 레벨의 증가량을 그대로 저장한다. 예를 들어 `+3, +3, +3`은 SO에 `3, 3, 3`으로 저장하고, 3레벨 효과는 `+9`다. 공격력은 정수, 범위는 월드 단위, 공격 간격 감소는 초 단위 음수, 치명타 확률은 퍼센트포인트, 치명타·보스 피해는 배율 가산분이다. 예를 들어 보스 피해 `0.01`은 `1.00%`로 표시한다.
- 몬스터 생성량과 필드 시간도 SO에 레벨별 증가량을 저장하며, 별도로 설정한 연구 기준값에 더한다. 기준값은 실제 게임 기본값을 확인해 설정한다. 0레벨은 게임 기본값을 사용한다. 생성량의 최종값은 1~16의 정수, 필드 시간은 15~30초다. 기본값이나 의도가 불분명하면 임의로 정하지 말고 확인한다.
- 스킬과 몬스터 해금은 1레벨·효과 값 `1`이다. 기본 몬스터 `monster.01`은 이미 해금되어 있다. 스킬 강화와 기본 몬스터 외의 생성량 연구는 해당 대상의 해금이 필수 선행 조건이다.
- 같은 맵에 동일 대상의 해금·몬스터 생성량·필드 시간 연구는 중복 배치할 수 없다. 커서 스탯과 허용된 스킬 강화의 별도 배치 효과는 합산된다.
- 현재 구현과 허용 대상은 `ResearchDefinition.cs`, `ResearchEffectCalculator.cs`, `ResearchMapDefinition.cs`, `ProgressionCombatSnapshot.cs`를 확인한다. SO와 텍스트 키, 효과·단위 및 실제 적용 경로를 검증하고 결과를 보고한다.
