# 테스트 치트 메뉴

Main 실행 중 `=` 키를 눌러 `Cheat_Canvas`를 열거나 닫는다. 텍스트를 입력 중일 때는 단축키를 처리하지 않는다. 버튼, 한국어 문구와 실행 결과 표시는 모두 Main 씬에 미리 배치되어 있다. `Cheat_Canvas/CheatViewport/Group`의 Grid Layout을 사용하며 영역이 넘치면 세로 스크롤한다.

## 치트 테이블 관리

Unity에서 [CheatTable.asset](../../Assets/CursorHunter/App/Resources/CheatTable.asset)을 선택하면 Inspector의 `Entries` 목록을 편집할 수 있다. 씬의 `UICanvas`에 있는 `CheatMenuController`는 `Button Bindings`에 등록된 버튼과 테이블을 ID로 연결한다. 버튼 순서와 문구는 씬에서 편집한다.

| 필드 | 용도 |
|---|---|
| `Id` | 비어 있지 않은 고유 식별자. 중복은 제외한다. |
| `Action` | 구현된 치트 동작 선택. 같은 동작을 다른 수치로 여러 번 등록할 수 있다. |
| `Amount` | `Add All Currencies`의 지급량. 현재 잔액에 더한다. |
| `Enabled` | 체크하지 않으면 연결된 버튼을 실행 중에 숨긴다. |

문구를 바꾸려면 Main 씬에서 `Cheat_Canvas`를 일시 활성화하고 각 버튼의 `Text`를 수정한다. 예를 들어 지급량을 변경하면 버튼 문구도 씬에서 함께 수정한다. 새 항목을 만들 때는 테이블에 행을 추가하고 `Group`에 버튼과 한국어 문구를 배치한 다음 `Button Bindings`에 같은 ID와 버튼을 연결한다. 다른 종류의 동작은 `CheatAction`과 `CheatMenuController.Execute`에도 추가한다. 버튼의 열 수·크기·간격은 `Group`의 `GridLayoutGroup`에서 편집한다.

## 새 치트 추가 절차

협업자가 치트를 추가할 때는 아래 단계를 한 변경으로 함께 반영한다. 플레이어 데이터를 실제로 수정하는 테스트는 별도 프로필 또는 별도 프로젝트 사본에서 실행한다.

1. **동작 구현:** 기존 동작으로 표현할 수 없으면 `CheatAction`에 새로운 고정 숫자 값을 덧붙이고 `CheatMenuController.Execute`에 분기를 추가한다. 기존 enum 값은 저장된 테이블을 위해 바꾸지 않는다. 진행도 변경은 Progression의 기존 저장·실패 복구 경로를 사용하고, 대기 보상 저장을 먼저 처리한다.
2. **테이블 등록:** `CheatTable.asset`의 `Entries`에 고유한 `Id`, `Action`, 필요하면 `Amount`를 입력하고 `Enabled`를 켠다. ID는 씬 버튼 연결에도 그대로 사용한다.
3. **씬 버튼 배치:** Main 씬에서 `UICanvas/Cheat_Canvas`를 편집용으로 활성화한다. `CheatViewport/Group`의 기존 버튼을 복제하고 이름을 `Cheat_<Id>`로 정한다. 자식 `Text`에 한국어 문구를 직접 입력하고 수치가 있다면 테이블 값과 맞춘다. 버튼·문구를 런타임에 생성하거나 바꾸지 않는다.
4. **연결:** `UICanvas`의 `CheatMenuController > Button Bindings`에 동일한 ID와 새 씬 버튼을 등록한다. 편집이 끝나면 `Cheat_Canvas`를 다시 비활성화하고 씬을 저장한다.
5. **검증:** Main 씬을 연 상태에서 Unity 메뉴 `Tools > Cursor Hunter > Cheats > Validate Main Cheat Menu`를 실행한다. 테이블·연결 ID 중복, 연결 누락, 버튼 위치와 한국어 문구를 확인한다. `CheatMenuSceneTests`와 `CheatMenuPlayModeTests`를 실행하고, 새 동작의 성공·저장 실패·경계값 및 재실행을 검증한다. 기존 테스트에 새 치트가 필요한 경우 기대값도 함께 갱신한다.

## 등록된 기능

| 버튼 | 동작 |
|---|---|
| 특성 카드 초기화 | 신규 카드·특성 레벨·특성 포인트를 초기화하고 유저 경험치 0, 유저 레벨 1로 저장한다. 새 잠금 후보를 준비한다. |
| 연구 진행 상황 초기화 | Main에 연결된 현재 연구 맵의 구매 랭크를 초기화한다. 다른 맵의 기록과 재화는 유지한다. |
| 유물 진행 상황 초기화 | 보유 유물과 미확인 표시를 초기화한다. |
| 모든 재화 999,999 지급 | 가넷부터 드래곤 젬까지 젬스톤 6종과 특성 포인트에 각각 999,999를 더한다. 반복 실행하면 다시 더하며 Int64 상한을 넘지 않는다. |
| 모든 재화 0으로 | 젬스톤 6종과 특성 포인트의 잔액을 0으로 설정한다. |
| 유저 레벨 1 올리기 | 현재 경험치를 다음 유저 레벨 시작점까지 올리고 일반 레벨업과 같이 특성 포인트 1개를 지급한다. 현재 레벨의 남은 경험치는 채워지며, 최대 레벨 25에서는 안내만 표시한다. |

각 치트는 위에 명시한 영향을 제외한 진행도를 보존하며 저장 실패 시 해당 변경을 되돌린다. 정산 대기 보상은 먼저 저장하고, 그 저장에 실패하면 치트를 실행하지 않는다. 완료된 치트는 재실행 후에도 유지된다. 치트는 테스트용이지만 별도 빌드 제한 없이 동작하며 버튼을 누르면 현재 프로필에 즉시 저장된다. 진행 중인 전투에는 기존에 확정된 전투 스냅샷이 유지되고 전투 중단은 하지 않는다.
