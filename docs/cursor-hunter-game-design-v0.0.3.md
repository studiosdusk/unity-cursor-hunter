# CURSOR HUNTER
## 세부 기획 · 화면 설계 · 밸런스 초안

상태: v0.0.3 개정 3 / 사용자 확정사항 + 조정 가능한 설계 초안
작성일: 2026-09-08
대상: Unity 2D / Steam PC / 마우스 커서 액션 아이들러

> 작은 원형 커서로 시작해 화면을 채운 몬스터 무리를 연쇄적으로 터뜨리는 약 2시간의 성장 게임. 처음에는 쓰러뜨리지 못하던 보스를 강화 후 돌파하고 v5 처치로 엔딩에 도달한다.

### 이번 개정에서 달라진 점

- 최신 참고 화면에 맞춰 특성을 고정 HUD + 자유 분기형 트리로 재설계했다.
- Splash부터 정산까지 화면 흐름과 상태 전이를 정의했다. 특성 3개 탭, 보스 선택, 실패 정산, 설정의 상세 와이어프레임을 추가했다.
- 기본 공격력·일반 몬스터 HP·보스 v1~v5 HP를 같은 피해 공식으로 연결했다. 특성 가격, 재화 공급, 해금 선후관계도 함께 정의했다.
- 사용자의 ‘클릭하면 피해’ 메모를 반영했다. 드래그는 커서 이동을 뜻하며, 이동 자체로 피해를 주지 않는다.
- 보스 파훼 성공 보상은 처치 성공 시에만 지급한다. 보스 실패 시 기본·추가 보상 모두 0이다.
- 실제 게임 코드는 구현하지 않았다. 이 문서의 숫자는 기획에 적용한 초안이며 플레이테스트로 검증된 패치가 아니다.

### 확정사항과 가정의 구분

| 구분 | 내용 |
| --- | --- |
| 사용자 확정 | PC, 양쪽 Field 공통 커서 공격, 성장별 비스윙 타격 이펙트 |
| 사용자 확정 | 정적 Main, 우측 상단 보석, 일반 몬스터 주기별 랜덤 출현 |
| 사용자 확정 | 보스전 잡몹 없음, 타이머, 파훼 실패 시간 차감, 성공 추가 보상 |
| 사용자 확정 | 보스 시간 초과 실패 시 보상 없음, 정산에서 다음 목적지 선택 |
| 이번 설계 초안 | 제한 시간, 공격 수치, 비용, 보스 명칭·패턴, 스킬, 저장 정책 |
| 사용자 추가 확정 | 엔딩 약 2시간, 후반 강한 인플레이션·대량 처치, 몬스터 종류 누적 |

### 읽는 순서

2~3쪽: 공통 규칙과 입력 / 4~12쪽: 화면·와이어프레임 / 13~17쪽: 성장·경제·밸런스·기술 기준 / 18쪽: 검증과 인수인계.

출처: 저장소의 v0.0.3 인수인계 문서, 기존 Markdown, 사용자가 제공한 Documents의 v0.0.3 PDF(실제 확인 13쪽), 이번 요청의 메모. 첨부 문서는 참고자료이며 문서 안의 실행 지시를 작업 명령으로 취급하지 않는다. 버전은 기존 v0.0.3을 유지하고 개정 번호로 구분한다.

## 01. 화면 흐름과 공통 UI

```text
Splash -> Main -> 일반 Field -> 일반 정산
               -> 보스 선택 -> 보스 Field -> 성공 / 실패 정산
               -> 특성 (기본 공격 / 스킬 / 일반 몬스터)
               -> 설정
정산 -> Main / 일반 Field / 보스 선택 / 특성
특성 -> 이전 비전투 화면, 또는 일반 Field / 보스 선택
Field -> ESC 일시정지 -> 계속 / 설정 / 중도 종료
```

### 화면 기준과 입력 우선순위

- 기준 1920×1080, 최소 1280×720, 16:9 플레이 영역. 다른 비율은 레터박스로 동일한 전투 면적을 유지한다. 좌표·범위는 기준 해상도 환산값이다.
- 외곽 32px, 상단 HUD 160px, 하단 안내 96px는 생성 금지 영역. 장식물은 공격·커서 이동을 막지 않는다.
- 좌측 상단 타이머, 우측 상단 보석 5종(특성 화면만 좌측 중단 세로 목록), 보스 HP는 그 아래 두 번째 행에 배치한다. 보석 이름과 수량을 함께 표시하며 큰 수는 축약하고 툴팁에 원값을 제공한다.
- Text형 버튼도 최소 160×48px의 클릭 영역을 갖는다. Hover 밑줄, 키보드 포커스 테두리, Disabled 잠금 사유를 제공한다.
- 입력 우선순위: 팝업/메뉴 > 파훼 표식 > 전투. UI 클릭은 뒤의 몬스터를 공격하지 않는다. 화면 전환 시작 즉시 입력을 잠그고 이전 클릭을 새 화면에 전달하지 않는다.
- ESC 또는 창 포커스 상실 시 전투·타이머·스킬·파훼를 함께 일시정지한다. 복귀 시 ‘계속’ 입력으로 재개한다.

### 재화 표시 초안

| 순서 | 보석 | 색상·형태 | 주요 사용처 |
| --- | --- | --- | --- |
| 1 | 가넷 | 붉은 원석 | 공격력, 몬스터 해금, 공통 비용 |
| 2 | 토파즈 | 황금 마름모 | 범위, 다중 클릭 |
| 3 | 자수정 | 보라 육각형 | 스킬, 자동 클릭 |
| 4 | 사파이어 | 파란 사각형 | 자동 속도, 후반 해금 |
| 5 | 다이아몬드 | 흰 별형 | 드래곤 브레스, 최종 성장 |

이름은 인수인계의 익숙한 보석명 제안을 초안으로 채택했다. 모든 화면에서 위 순서·색상·형태를 통일한다. 특성 화면의 보석 위치는 좌측 중단이며 전투·Main의 우측 상단 규칙과 구분한다. 잠긴 보석도 0과 이름을 표시한다. 런 중 HUD는 ‘보유’와 ‘이번 판 +N’을 분리해 아직 확정되지 않은 보상을 구분한다.

## 02. 공격 판정과 전투 종료

### 커서 공격

- 최초 공격력 A=10, 커서 반경 R=18px, 좌클릭 누름 1회당 1묶음 공격. 커서 원과 몬스터 판정 원이 겹치면 명중한다. 홀드·이동 자체는 공격하지 않는다.
- 범위 안의 모든 살아 있는 몬스터에 같은 피해를 적용한다. 다중 클릭 M=1/2/3은 서로 더하지 않고 가장 높은 단계만 사용한다.
- 더블/트리플은 같은 시점·같은 대상 목록에 2/3회 타격한다. 첫 타격으로 사망하면 남은 타격은 무효이며 인접 대상에 넘기지 않는다. ‘병렬’은 동시 타격 연출이며 멀티스레드 처리를 요구하지 않는다.
- 자동 클릭 해금 후 커서 위치에서 초당 10회 공격 묶음을 발생시킨다. 속도 특성으로 15/20/25/30회까지 성장한다. 자동 ON 중 수동 클릭은 추가 기본 피해를 발생시키지 않으며 파훼 입력은 정상 처리한다. 자동 OFF이면 수동 공격 가능하다.
- 수동 입력은 최대 초당 8묶음으로 제한하는 초안이다. 밸런스 기준은 편안한 초당 2클릭이다. 자동 모드는 대상이 없으면 피해가 없고 UI·정지·화면 밖에서 멈춘다.
- 자동 클릭·스킬·다중 타격은 파훼 표식을 해결하지 않는다. 파훼는 직접 좌클릭이 필요하다.

### 시간·정산 원칙

일반 Field 60초, 보스 Field 60초. 시간은 일시정지를 제외한 실제 전투 경과 시간으로 계산한다. 보스 실패 패널티는 남은 시간에서 별도로 차감한다. 보스 HP가 0이면 즉시 전투를 멈추고 0.6초 처치 연출 후 정산한다. 일반 Field는 시간 종료 때 생존 몬스터를 보상 없이 제거한다.

종료 경계는 이벤트 시각 순으로 처리한다. 남은 시간이 양수인 시각의 타격만 유효하며, 정확히 만료 시각의 타격은 무효다. 같은 시각이면 시간 만료/패널티에 따른 만료를 먼저 처리한다. 종료는 한 번만 실행한다.

### 보상과 DPS

- 일반 몬스터 사망 때 런 보상을 즉시 기록한다. 보석의 0.35~0.65초 자석 연출 완료 여부는 수량에 영향을 주지 않는다. 일반 정상 종료·중도 종료 모두 확정된 처치 보상을 지급한다.
- 보스 보상과 파훼 보너스는 처치 성공에서만 한 번 확정한다. 시간 초과·중도 종료는 모두 0. 입장료는 없다.
- 실측 DPS = 실제 HP 감소량 합계 / 실제 전투 경과 초. 과잉 피해는 제외하고 스킬 피해는 포함한다. 0초면 DPS 0, 표시는 소수점 1자리다. 시간 패널티를 분모에 더하지 않는다.
- 이론 DPS는 특성 화면의 비교 수치로 별도 표시한다. 일반 실측은 몬스터 공급·이동에 영향을 받아 보스 실측보다 낮을 수 있다.

## 03. Splash · Main

### Splash 와이어프레임
```wireframe splash
중앙 로고 / 하단 초기화 진행 / 실패 시 재시도와 종료
```

초기화가 끝난 뒤 최소 0.8초 로고를 표시하고 Main으로 이동한다. 준비 완료 후 클릭/Enter로 건너뛸 수 있다. 저장 읽기 실패는 새 게임으로 자동 덮어쓰지 않고 백업 복구·재시도·종료 선택을 제공한다.

### Main 와이어프레임
```wireframe main
정적 평원 / 중앙 Text 메뉴 / 우측 상단 보석 보유량
```

몬스터·공격·타이머가 없는 정적 배경이다. 일반 진입은 메뉴 0.25초 Fadeout 후 HUD 0.2초 Fadein, 완료 순간 첫 몬스터 생성과 60초 타이머를 시작한다. 보스 버튼은 보스 선택으로 이동한다. 특성·설정에서 복귀하면 Main 메뉴의 마지막 포커스를 복원한다.

## 04. 일반 Field

### 전투 와이어프레임
```wireframe normal-field
타이머 60초 / 보유와 이번 판 보석 / 랜덤 몬스터 / 이동하는 커서 / 자동 ON 상태
```

### 생성과 화면 피드백

- 슬라임은 처음부터 해금. 구입한 종은 모두 고유 주기로 출현한다. 등장 종 선택이나 장착 제한 없이 누적한다.
- 입장 t=0에 종별 첫 묶음, 이후 각 주기마다 묶음을 생성한다. 종료 시각 t=60에는 생성하지 않는다. 적은 주변 80px 내에서만 천천히 배회하며 화면 밖으로 이탈하지 않는다.
- 전체 생존 상한은 진행도에 따라 80/180/350/600/900/1,200마리. 각 종은 기본 주기마다 1/3/6/10/16/20마리 묶음을 생성하고 보스 처치별 공통 묶음 배율을 적용한다(14장). 한 묶음은 반경80px 군집으로 퍼뜨린다. UI·화면 밖을 피하되 몬스터끼리 겹침은 허용한다. 위치를 8회 시도한 뒤 실패하면 해당 개체를 생략한다. 밀린 생성은 누적하지 않는다.
- 몬스터 머리 위 HP 바는 피격 후 1초 표시한다. 처치 시 형체가 보석으로 바뀌어 우측 상단 해당 슬롯으로 이동한다. 도착 시 +N 팝업은 0.1초 단위로 합친다.
- 커서 외곽선은 실제 공격 반경이다. 이펙트 크기와 판정 범위를 혼동하지 않게 한다. 자동 해금 후 하단에 ‘자동 ON/OFF [A]’와 묶음/초를 표시한다.
- 남은 10초부터 숫자 강조와 초당 1회 약한 경고음. 0초에 생성·피해 중지, 생존 몬스터 Fadeout, 0.4초 후 정산.

### 예외 상태

생성 상한에 도달하면 해당 묶음을 생략하고 타이머는 계속 흐른다. 종별 큐는 라운드로빈 처리해 낮은 종이 계속 밀리지 않게 한다. 빈 필드에서 클릭해도 비용·패널티는 없다. ESC 중도 종료에는 ‘현재까지 처치 보상을 받고 종료’ 문구를 표시한다. 런 중에는 특성을 구매할 수 없다.

## 05. 보스 선택 · 입장

### 보스 선택 와이어프레임
```wireframe boss-select
왼쪽 v1~v5 / 중앙 보스 요약 / 오른쪽 HP·보상·추천 성장 / 하단 도전
```

### 선택 규칙

| 보스 | 선택 가능 조건 | 첫 처치 핵심 해금 | 반복 플레이 목적 |
| --- | --- | --- | --- |
| v1 슬라임 킹 | 처음부터 | 더블 클릭, 고블린, 파이어 볼 | 가넷·토파즈 |
| v2 고블린 족장 | v1 처치 | 트리플 클릭, 오크, 라이트닝 | 자수정 공급 |
| v3 오크 워로드 | v2 처치 | 자동 클릭, 골렘, 프리징 | 자동화 성장 |
| v4 수정 골렘 | v3 처치 | 자동 속도, 와이번, 허리케인 | 사파이어·다이아몬드 |
| v5 고대 드래곤 | v4 처치 | 일반 드래곤, 드래곤 브레스 | 최종 성장·효율 갱신 |

해금은 구매 자격을 연다. 더블/트리플/자동 클릭·스킬·몬스터는 특성에서 별도 구매한다. 이미 처치한 보스는 반복 도전 가능하며 다음 보스가 자동 선택된다. 잠긴 행에는 선행 보스 이름을 표시한다.

### 정보와 버튼

- 선택 보스의 HP, 제한 시간, 패턴, 기본 보상, 최초 해금, 현재 이론 DPS를 표시한다.
- 추천 공격력 레벨은 참고이며 입장을 막지 않는다. 도전 가능 조건은 선행 보스 처치뿐이다.
- ‘도전’ 선택 후 0.3초 Fade, 보스 등장 0.6초 후 타이머 시작. 준비 연출 중 피해·파훼·시간 차감은 없다.
- 돌아가기 또는 ESC는 진입한 Main/정산으로 복귀한다. 최초 해금 결과는 저장 후 표시해 중복 지급을 방지한다.

## 06. 보스 Field · 파훼

### 전투 와이어프레임

| --- | --- | --- | --- | --- |

입력 창 전체에서 표식을 순서대로 누르면 1회 성공. 잘못된 클릭은 진행하지 않고 짧은 피드백만 주며, 창이 끝나면 이벤트당 1회 실패 처리한다. 성공하면 표식 제거와 ‘처치 시 보너스 +5%’를 표시한다. 보너스는 보스 기본 보석 각 종류에 +5%, 최대 5회/25%; 종류별 내림한다. 시간 연장·추가 피해는 없다. 처치 시 진행 중인 이벤트는 취소하며 실패를 부과하지 않는다.

## 08. 특성 화면 · Stat / 자유 분기

### Stat 탭 와이어프레임
```wireframe traits-attack

```

### 배치와 탐색

- 참고 스크린샷의 넓은 연결형 노드 맵을 적용한다. 좌측 상단 Stat·Skill·Monster 탭, 우측 상단 현재 특성 막대 그래프, 좌측 중단 5종 보석을 고정한다. Monster가 정식 표기다.
- 1920×1080 기준 상단140px, 좌측 재화260px, 하단 상세160px를 고정 UI로 두고 나머지를 트리 캔버스로 사용한다. 탭별 이동·확대·선택 상태를 기억한다.
- 빈 공간 좌클릭 드래그/중클릭으로 이동, 휠로 60~160% 확대한다. 노드에서 누른 뒤6px 이상 움직이면 탐색으로 처리해 구매·선택 오작동을 막는다. ‘전체 보기’와 ‘선택 위치’ 버튼을 제공한다.
- 노드 선택 후 하단에 현재→다음 효과, 선행 조건, 보유/필요 재화, 구매를 표시한다. 고정 UI는 트리와 함께 움직이지 않는다. 화면 밖 노드를 방향 표시로 안내한다.

### 자유 선택 규칙

공통 시작점은 무료다. Stat의 공격력·범위·다중 클릭·자동화는 독립 가지이며, 어느 가지를 먼저 구입할지는 플레이어가 선택한다. 가지를 고르면 다른 가지가 잠기지 않고, 여러 가지에 나눠 투자할 수 있다. 보스 해금은 유지하되 다른 가지의 구매를 강제하지 않는다.

같은 가지 안에서는 직전 단계만 필요하다. 더블→트리플, 자동→속도, 공격력·범위의 레벨 순서는 유지한다. 자동은 v3 처치만으로 구매 가능하며 트리플 구매를 요구하지 않는다. 연결선은 부모→자식 선행 조건을 뜻한다. 시작점에서 뻗은 서로 다른 가지 사이에는 선행선이 없다. 보스 잠금은 노드 배지로 별도 표시한다.

## 09. 특성 화면 · Skill

### 스킬 탭 와이어프레임
```wireframe traits-skills
고정 탭·좌측 보석·우측 요약 / 공통 시작점에서 스킬별 분기 / 각 스킬의 강화 노드 / 하단 상세
```

### 자동 스킬 초안

각 스킬은 공통 시작점의 독립 가지다. 파이어 볼을 구매하지 않아도 v2 조건과 비용을 충족하면 라이트닝부터 구매할 수 있다. 개별 스킬 강화만 해당 스킬 구매를 요구한다. 해금 후 구매한 스킬은 모두 자동 장착된다. 유효 대상이 있을 때 자동 발동하며 커서 근처 적을 우선한다. 쿨다운 준비 상태에서 대상이 없으면 대기하고 대상 등장 시 발동한다. 각 런 시작 때 준비 완료, 정지 동안 쿨다운 정지. 파훼 입력을 대신하지 않는다.

| 스킬 | 구매 조건·비용 | 피해 / 주기 | 대상·부가 효과 |
| --- | --- | --- | --- |
| 파이어 볼 | v1 / 가넷 1,500 + 토파즈 10 | 3A / 6초 | 커서 근처 120px 폭발 |
| 라이트닝 볼트 | v2 / 가넷 40,000 + 자수정 12 | 대상별 0.8A / 8초 | 최대 3대상, 보스에는 1타 |
| 프리징 | v3 / 가넷 1백만 + 자수정 25 | 1A / 12초 | 140px, 일반 적 이동 2초 정지 |
| 허리케인 | v4 / 가넷 3천만 + 사파이어 12 | 0.5A×6틱 / 15초 | 180px, 3초 지속 |
| 드래곤 브레스 | v5 / 가넷 3억 + 다이아몬드 10 | 1A×8틱 / 20초 | 커서 중심 220px, 2초 지속 |

A는 해당 런 공격력이다. M·클릭 속도는 스킬 피해에 곱하지 않는다. 지속 피해는 첫 틱을 즉시 적용하고 이후 허리케인은 0.5초, 브레스는 0.25초 간격으로 적용한다. 프리징은 보스·파훼·타이머를 멈추지 않는다. 고정 방향의 휘두르기 대신 충돌 폭발·전류·서리 문양·소용돌이·커서 중심 화염 분출로 표현한다.

각 스킬 강화 0~5레벨, 피해 배율 1+0.1×레벨. 다음 비용은 가넷 ceil(B×1.5^현재레벨)와 자수정 5×(현재레벨+1). B는 스킬 순서대로 2,000/80,000/5백만/2억/50억이다. 드래곤 브레스만 보조 비용을 다이아몬드 2×(현재레벨+1)로 대체한다. 쿨다운 감소는 이번 초안에서 제외해 자동 발동 과밀을 억제한다.

### 몬스터 원장

| 몬스터 | HP | 기본 주기 | 처치 보상 | 해금 조건·비용 |
| --- | --- | --- | --- | --- |
| 슬라임 | 20 | 1.5초 | 가넷 3 | 처음부터 무료 |
| 고블린 | 80 | 3초 | 가넷 7 + 토파즈 1 | v1 / 가넷 120 |
| 오크 | 800 | 4초 | 가넷 15 + 자수정 1 | v2 / 가넷 250 + 토파즈 10 |
| 골렘 | 12,000 | 5초 | 가넷 30 + 사파이어 1 | v3 / 가넷 450 + 자수정 15 |
| 와이번 | 600,000 | 6초 | 가넷 60 + 사파이어 2 | v4 / 가넷 800 + 사파이어 15 |
| 드래곤 | 30,000,000 | 10초 | 가넷 140 + 다이아몬드 1 | v5 / 가넷 1,200 + 다이아몬드 5 |

종별 해금은 다른 종 구매와 독립이다. 보스 조건만 충족하면 원하는 종부터 해금할 수 있다. 해당 종 해금에서 출현 강화와 보상 강화가 나뉘며 둘 중 어느 쪽도 다른 쪽을 요구하지 않는다. 드롭은 기본 확정 수량이다. 가넷에만 14장의 진행도 보상 배율을 곱하며 희귀 보석에는 곱하지 않는다. 확률 드롭은 사용하지 않는다. HP는 공격력에 맞춰 자동 상승하지 않는다. 작은 커서로도 대상마다 조준 가능하도록 몬스터 판정 반경은 슬라임부터 24/28/34/42/48/60px로 둔다.

### 종별 강화

- 출현 강화 0~3: 주기 = 기본 주기 / (1+0.15×레벨). 다음 비용 가넷 ceil(B×2^현재레벨), 해당 종 해금 후 구매 가능.
- 보상 강화 0~3: 가넷 = floor(기본 가넷×(1+0.2×레벨)×진행도 보상 배율). 희귀 보석 수량은 고정. 다음 비용 가넷 ceil(1.5×B×2^현재레벨). B는 슬라임부터 100/2,000/80,000/5백만/2억/50억이다.
- HP·주기·드롭·전체 상한은 상세 창에서 미리 보여준다. 강화로 적체가 늘 수 있음을 알려주되 구매를 막지 않는다. 해금된 몬스터는 끝까지 중첩 출현하며 교체·비활성화하지 않는다. 후반에도 슬라임부터 모든 종이 화면에 섞인다.

## 12. 기본 공격 특성 · 급격한 성장 곡선

### 공격력 구간 공식

L=0~30. 각 구간 시작 레벨 l0와 시작 공격력 a0, 끝 공격력 a1에 대해 A=round(a0×(a1/a0)^((L-l0)/5)). 경계 레벨은 다음 구간 시작과 동일하다. 양수 반올림은 0.5 이상 올림이다.

| 레벨 구간 | 시작→끝 공격력 | 현재 L의 다음 레벨 가넷 비용 | 열리는 시점 |
| --- | --- | --- | --- |
| 0→5 | 10→21 | ceil(30×1.18^L) | 시작 |
| 5→10 | 21→100 | ceil(2,000×1.35^(L-5)) | v1 처치 |
| 10→15 | 100→1,000 | ceil(80,000×1.35^(L-10)) | v2 처치 |
| 15→20 | 1,000→20,000 | ceil(5,000,000×1.35^(L-15)) | v3 처치 |
| 20→25 | 20,000→1,000,000 | ceil(200,000,000×1.35^(L-20)) | v4 처치 |
| 25→30 | 1,000,000→100,000,000 | ceil(5,000,000,000×1.35^(L-25)) | v5 이후 선택 성장 |

기본 공격력은 엔딩 권장 상태까지 10만 배, 최종 선택 성장까지 1,000만 배 오른다. 몬스터 HP는 고정되어 옛 적이 순식간에 터지고 새 종과 보스가 다음 성장을 요구한다.

| 특성 | 조건 | 효과 | 비용 |
| --- | --- | --- | --- |
| 더블 클릭 | v1 | M=2 | 가넷100 + 토파즈8 |
| 트리플 클릭 | v2 + 더블 | M=3 | 가넷5,000 + 토파즈25 |
| 범위 1~6 | 시작/v1/v2/v3/v4/v5 각1단계 | R=36/60/96/150/240/360px | 가넷80/2,000/40,000/2백만/5천만/10억 |
| 자동 클릭 | v3 (다중 클릭과 독립) | 초당10묶음 | 가넷1백만 + 자수정30 |
| 자동 속도 1~4 | v4 + 자동 | 15/20/25/30묶음 | 가넷1천만/2천만/4천만/8천만 + 사파이어10/20/30/40 |

자유 분기에서도 이 표의 비용·보스 해금·동일 가지 순서는 적용한다. 자동을 먼저 구입하면 보유한 M=1/2/3으로 동작한다. M은 최고 단계만 적용된다. 30묶음×3타=90타/초. 범위는 다수 적에게 동일 피해를 주므로 후반 대량 처치의 핵심 구매다. UI는 ‘반경’과 ‘묶음/초’를 구분한다. 치명타·랜덤 무기 옵션은 첫 검증에서 제외한다.

추천은 동일한 클릭 판정을 유지하며 자동10→30회로 성장시키는 방식이다. 즉시30회는 구현이 단순하지만 성장 단계가 하나 사라지고 부하가 급증한다. 단계형은 속도 레벨 관리가 추가되지만 밸런스·성능 측정과 후반 확장에 유리하다.

### 그래프와 노드 상태

그래프는 공격력 L/30, 범위 Lv/6, 다중 타격 M/3, 자동 속도 F/30의 고정 최종 기준 대비 막대와 실제 수치를 표시한다. 자동 미구매는0이다. 탭을 바꿔도 요약을 유지하며 클릭하면 보유 스킬·종별 강화·이론 DPS 상세를 펼친다. 서로 다른 단위를 합산한 종합 점수는 만들지 않는다.

구매 완료는 체크, 구매 가능은 밝은 테두리, 재화 부족은 부족량, 선행/보스 잠금은 조건, 최고 레벨은 MAX로 구분한다. 노드 선택은 구매가 아니다. 비전투에서만 구매·저장하고 다음 Field에 적용한다. 환불은 초안에서 제외하되 모든 가지를 최종 구매할 수 있다. 추천 경로를 필수 경로처럼 표시하지 않는다.

### 실패→성장→돌파

다음 보스는 직전 보스 처치 후 즉시 도전할 수 있다. 처음에는 화력 부족을 경험하고 정산에서 ‘공격력 성장 후 재도전’을 안내한다. 자동 잠금이나 필수 실패 횟수는 없다. 실력과 구매 순서에 따라 조기 처치도 허용한다.

## 16. 성장 이펙트 · 저장 · 성능 기준

### 공격 성장의 시각 언어

| 조건 | 형태·색상 | 크기·지속 | 가독성 규칙 |
| --- | --- | --- | --- |
| 초기 | 흰 점 + 작은 원형 파편 | 판정 반경×1.0 / 0.08초 | 타격 지점 고정 |
| 더블 구매 | 황금 이중 링 | 반경×1.1 / 0.10초 | 2타 숫자 묶음 |
| 트리플 구매 | 보라 삼각 파편 + 3중 점 | 반경×1.15 / 0.12초 | 3타 표시 |
| 자동 구매 | 청색 맥동 링 | 반경×1.2 / 0.12초 | 0.1초 단위 연출 합산 |
| v5 처치 | 흰 결정 문양 + 화염 점 | 반경×1.0 / 0.15초 | 표식보다 낮은 레이어 |

이 단계는 별도 무기 아이템 대신 공격 성장의 시각 등급이다. 이펙트 크기는 연출 전용이며 피해 반경은 범위 특성 R만 따른다. 휘두르는 궤적·검기는 쓰지 않는다. 숫자·링 합산은 논리적 타격 수와 재화 수량을 줄이지 않는다.

### 저장·예외 처리 초안

보유 재화, 특성 레벨, 보스 최초 처치, 몬스터·스킬 구매, 설정, 최근 정산을 로컬 저장한다. 일반 런 처치 기록은 주기적 체크포인트(5초)와 정상 종료 시 저장한다. 강제 종료는 마지막 체크포인트의 일반 보상만 회수하며 최대 5초 손실 가능성을 인정한다. 보스 미완료 런은 복구 시 보상 없이 종료한다. 완료된 보스 정산은 다시 지급하지 않는다.

정산 고유 ID, 지급 여부, 재화 잔액을 하나의 저장 단위로 기록하고 임시 파일 기록 후 교체·백업한다. 저장 실패 시 결과 화면에 재시도/종료 안내를 표시하고 이동·구매를 잠근다. 이 구조는 구현 제안이며 기존 클래스가 존재한다는 뜻이 아니다. Steam Cloud·오프라인 자동 수입은 이번 초안 범위 밖이다.

### 구현 시 반드시 검토할 위험

- 메모리: 적·보석·숫자·타격 이펙트 풀링과 런 종료 시 콜백 해제. 후반 큰 커서의 이펙트는 화면의20% 이상 불투명하게 덮지 않도록 외곽 링 위주로 제한한다. 최대 상한 적1,200/보석 연출60/타격 연출100. 사용하지 않는 풀은 화면 전환에서 정리한다.
- 경쟁 상태: 전투 판정·사망·종료는 단일 실행 흐름에서 처리하고 정산 ID로 중복 지급을 차단한다. ‘병렬 클릭’을 스레드로 구현하지 않는다.
- 성능: 30묶음×1,200대상×3타 최대 108,000 논리 타격/초. 공간 분할 조회·동시 피해 합산·적별 HP 바 생략·배치 렌더링이 필요하다. 60FPS 목표는 측정 전 가정이다. 논리 처치량을 줄이기 전에 보석·숫자·파티클 표시 수를 제한한다.
- 잘못된 참조: 풀로 반환한 적을 지연 스킬이 다시 때리지 않게 생존 ID를 재검사한다. 대상이 없으면 쿨다운 준비 상태를 유지한다.
- 경계·기존 영향: 시간0, HP0, 저장 오류, 다중 클릭 사망, 연출 중 종료를 검사한다. 기존 Unity 게임 코드에는 이번 작업의 변경이 없다.

### 이번 문서 검증 범위와 추천

공격력 공식, 비용 누적, 보스 DPS·처치 시간, 일반 보상 공급 상한, 재화 접근 순서를 계산으로 검증한다. PDF는 전 페이지 렌더링으로 확인한다. 체감 난이도·메모리·실행 성능·Unity 컴파일은 실제 구현 이후 검증 대상이며 이번 문서 작업만으로 통과했다고 판단하지 않는다.

추천은 기존 커서 클릭 구조를 유지하는 60초 런 + 약2시간 v5 엔딩 + 중첩 물량·급격한 성장안이다. 장점은 강화 체감과 데이터 조정의 명료함, 단점은 초반 클릭 피로와 자동 이후 수입 급증 가능성이다. 해당 부작용은 위 계측 항목으로 확인한다. 엔딩 약2시간·강한 인플레이션·대량 처치·종 누적은 사용자 확정이다. 보석명·세부 수치는 초안 표기를 유지하고 플레이테스트에 따라 조정한다.
