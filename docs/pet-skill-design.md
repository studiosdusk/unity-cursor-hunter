# BabyDragon 펫 스킬 기획·구현

상태: 마우스와 독립적인 탐색·추적·공격으로 변경 · 2026-10-28. Main 전투 화면의 크기·정렬·이펙트 수동 확인은 별도다.

BabyDragon은 일곱 번째 자동 스킬로 취급한다. 해금한 런에서 한 마리가 등장하고, 가까운 적을 스스로 찾아 이동·공격한다. 기존 `skill.cursorAura`의 커서 중심 범위 공격이나 v0.0.4의 펫 노드 수치를 이어받지 않는다. 전투 피해·처치·보상과 런 수명주기는 현재 여섯 스킬이 사용하는 경로를 따른다.

## 현재 코드에서 이어받을 구조

| 단계 | 현재 경로 | BabyDragon 적용 |
|---|---|---|
| 해금과 저장 | `progression-config.en.json` 구매 노드 → `GameInformationBuilder` → `GameInformation.skills` | 고정 ID `skill.pet_baby_dragon`의 해금 노드 추가. 구매 결과는 다음 런부터 적용 |
| 런 시작 | `HuntManager` → `RunCoordinator.Start` → `CombatRunController.PrepareRun/ConfigureSkills/CommitStart` | `IRunSkillController` 구현체가 해금 스냅샷을 받고 한 마리의 런타임 스탯을 고정 |
| 개별 실행 | 각 스킬 컨트롤러가 `CombatRunController.ElapsedSeconds`로 동작 | 펫의 탐색·이동·공격 시계를 펫 컨트롤러가 소유 |
| 피해와 정산 | `CombatRunController.TryApplyPetDamage` | 펫 전용 유물 보정을 적용하고 `CombatDamageSource.Skill`로 피해를 전달. 치명타·보스 배율·처치·보상·DPS는 공통 경로 사용 |
| 종료와 재사용 | `StopSkill`, `RunId`, 일시정지/만료 검사 | 펫을 비활성화하고 대상·공격 예약·연출 상태를 초기화 |

`Combat`은 `App`의 커서 컨트롤러 타입이나 `Progression` 저장소를 참조하지 않는다. 펫 컨트롤러에는 커서 앵커가 없으며, 등장·대기·탐색·추적·명중 모두 마우스 위치나 방향을 사용하지 않는다.

## 게임 동작

1. 펫 스킬이 잠겨 있으면 BabyDragon은 전투 중에도 보이지 않는다. 해금되어 있으면 전투 시계가 시작된 직후 씬에 배치된 위치에 한 마리가 나타난다. 첫 준비 때 위치를 기억하고, 다음 런에서도 같은 위치로 복원한다. 보스전도 같은 런 수명주기를 쓰며, 보스 대상의 등록 경로는 실제 보스 전투를 연결할 때 확인한다.
2. 대상이 없을 때 0.1초 간격으로 자신의 탐지 반경 안에서 현재 런에 등록되고 공격 가능한 적 중 가장 가까운 대상을 선택한다. 거리는 적 중심이 아닌 피격 영역의 가장 가까운 점을 기준으로 한다. 대상을 잡은 뒤에는 죽거나, 비활성화·등록 해제되거나, 무적이 되거나, 런이 달라질 때까지 유지한다. 탐지 반경은 새 대상 선택에만 적용한다.
3. 대상이 공격 사거리 밖이면 이동 속도에 따라 접근한다. 사거리 안에서는 멈춰서 단일 대상을 공격한다. 대상을 잃으면 현재 위치에서 재탐색하고, 탐지되는 적이 없으면 제자리에서 대기한다. 커서 복귀 및 커서 기준 추적 거리 제한은 없다.
4. 공격 주기가 준비되고 대상이 사거리 안에 있으면 물리 좌표를 동기화해 사거리를 확정한 뒤 Spine `Attack`을 매번 처음부터 재생한다. 공격 중에는 이동·방향 전환·재탐색을 하지 않는다. 전투 시계의 최소 공격 시간과 실제 Spine 트랙 완료를 모두 확인한 뒤 Idle로 전환하고, 다음 프레임부터 이동을 허용한다. 공격 진입·종료의 혼합 시간은 해당 트랙에서만 0으로 설정해 걷기와 공격 자세가 겹치지 않게 한다.
5. 실제 피해 시각은 런 전투 시계로 약 0.167초 뒤에 예약하며, 명중 순간 대상의 런 ID·활성 상태·무적·사거리를 다시 확인한다. Spine 이벤트 콜백으로 피해를 주지 않아 한 공격의 피해는 한 번만 적용한다. 공격 시작 후 적이 사거리 밖으로 이동하거나 죽거나 무적이 되면 피해가 취소되며, 이미 사용한 공격 주기는 유지한다.
6. 펫은 적의 피격 대상이 아니며 적 이동과 커서 공격을 가로막지 않는다. 한 번의 공격은 한 대상에게 한 번만 적용한다.

### 첫 플레이테스트용 기본값

| 스탯 | 초안 | 의미 |
|---|---:|---|
| 피해 배율 | 플레이어 런 시작 공격력 ×0.5 | `SkillStatMath.ScaleDamage`로 정수 피해를 만들고 공통 피해 경로에 전달 |
| 공격 간격 | 1.2초 | 공격 속도 약 0.83회/초. 한 필드에 하나의 공격 시계 |
| 이동 속도 | 초당 4 월드 단위 | 목표 추적에 사용 |
| 탐지 반경 | 8 월드 단위 | 펫 위치에서 새 대상을 찾는 거리 |
| 공격 사거리 | 1.5 월드 단위 | 적의 피격 영역에서 가장 가까운 지점까지의 거리 |

이 숫자는 성장 수치가 아니라 `PetSkillController` 프리팹과 Main 인스턴스 Inspector의 **첫 플레이테스트용 BaseStat**이다. 전투 진입 때 `PetRuntimeStat`을 한 번 계산한다. 현재 성장 노드는 가넷 40개로 구매하는 해금 하나뿐이며, 피해 배율·공격 간격·이동 속도·탐지 및 공격 사거리의 구매 강화 단계는 첫 플레이테스트 뒤 결정한다. 런 스냅샷의 해당 증가량은 이미 적용 가능하다. 공격 간격은 Spine 공격 클립 길이 0.5초보다 짧아지지 않게 제한한다.

## BabyDragon 애니메이션과 씬 에셋

`Export/BabyDragon.json`에는 `Idle`, `Walk`, `Attack`, `Busking`이 있다. `Attack` 길이는 0.5초이고 `Attack` 이벤트는 약 0.167초 지점이다. 대기·이동·공격 상태에 각각 `Idle`·`Walk`·`Attack`을 사용한다. `Busking`은 전투 동작에 쓰지 않는다. 일시정지에는 Spine 재생도 멈추며, 재개할 때 현재 상태를 이어간다.

Main에 배치된 `Spine GameObject (BabyDragon) (1)`은 씬 최상위의 프리팹 인스턴스다. 자식으로 사용자가 배치한 `MagicCircle1_Green` 고리 프리팹 인스턴스가 있다. 이 **씬 인스턴스와 자식 고리를 펫 전투 개체로 사용**한다. `PetSkillController`가 씬 인스턴스를 직접 참조해 해금 전과 런 종료 후에 숨기고, 전투 시작 때 처음 기억한 씬 위치로 복원해 활성화한다. 공급사 프리팹과 사용자가 조정한 씬 인스턴스를 재구성하거나 덮어쓰지 않는다.

`PetSkillController` 프리팹 인스턴스는 Main의 `CombatManager` 아래에 한 개 둔다. 컨트롤러는 Main에 있는 펫 한 마리를 참조해 런마다 재사용한다. 매 공격마다 펫을 생성하지 않는다. `Combat` asmdef에는 `spine-unity`와 `spine-csharp` 어셈블리 참조를 추가했다.

공격 명중 연출은 사용자가 지정한 `Assets/DownLoadAssets/Casual_VFX/Cartoon Casual VFX Pack/Prefabs/Explosion/Explosion_Effect_Blue.prefab`을 쓴다. 피해가 확정되는 순간 적의 피격 지점에서 한 번 재생한다. 파티클은 시각 연출이고 피해 판정은 `TryApplyPetDamage` 경로가 담당한다. 이 원본 프리팹의 루트 스케일은 3이고 여섯 ParticleSystem이 모두 반복·자동 재생으로 설정되어 있다. 컨트롤러는 복제한 파티클의 반복을 끄고 방출을 0.3초 뒤 멈춘다. 최대 8개를 런 준비 때 미리 만들고, 효과가 끝나면 풀로 돌린다. 풀이 모두 사용 중이면 해당 타격의 VFX만 생략한다. 공급사 원본과 사용자가 조정한 설정은 건드리지 않는다.

## 전투 중 아군 식별

BabyDragon은 청록색이며 적 몬스터도 여러 색의 귀여운 캐릭터로 구성된다. 캐릭터 색만으로 편을 구분하지 않고, 한 마리만 등장하는 펫에 일관된 **형태·위치·색** 신호를 준다.

| 방법 | 효과 | 적용 판단 |
|---|---|---|
| 머리 위 작은 별 배지 | 겹쳐 보일 때도 아군임을 형태로 식별 | 고리만으로 구분이 어려울 때 추가 |
| 발밑 얇은 아군 고리 | 이동 중 펫의 위치를 계속 추적 | Main의 BabyDragon 자식 `MagicCircle1_Green`을 그대로 사용 |
| 씬에 지정된 등장 위치 | 매 전투의 시작 위치를 예측 가능 | 등장 때만 복원하며, 전투 중 대기는 현재 위치에서 유지 |
| 약한 Spine 외곽광 | 적과 겹쳤을 때 실루엣 보강 | 실제 전투 화면에서 기본 표식만으로 부족할 때 추가. 게임 소유 머티리얼 사용 |
| 등장·명중 순간의 아군색 VFX | 소환 및 펫 공격의 출처를 알림 | 지속 광원 대신 짧은 연출로 추가 가능 |

**현재 구현 기준:** 기존 자식 고리를 펫과 함께 이동·표시하고, 대기 시 현재 위치를 유지한다. 고리는 공격·이동 애니메이션 중에도 읽혀야 한다. 녹색 필드와 몬스터가 겹치는 실제 전투 장면에서 고리의 대비·크기·정렬 순서를 확인하고, 부족할 때 머리 위 배지나 약한 외곽광을 추가한다.

펫 루트에는 런 준비 때 `SortingGroup`을 한 번 구성한다. BabyDragon은 몬스터와 같은 Default Sorting Layer 및 화면 Y 기반 0~199 Sorting Order를 사용하며, 아래쪽에 있을수록 앞에 보인다. 자식 `MagicCircle1_Green`에는 별도의 `SortingGroup`을 두고 `Sort At Root`를 켜서 부모의 정렬 순서에서 분리한다. 고리는 Default Sorting Layer의 Order -1로 고정되어 모든 몬스터 뒤에 그려지고, Transform 자식 관계는 유지되어 펫과 함께 이동한다. 펫 본체의 정렬은 등장·이동 직후에만 갱신하고, Y가 그대로이면 카메라 좌표 계산을 건너뛰며, 계산한 순서가 같으면 값을 다시 쓰지 않는다. 타격 이펙트 200과 체력바 250은 그 앞에 남는다.

## 데이터와 코드 변경 범위

1. **Contracts/Data:** `skill.pet_baby_dragon`을 알려진 스킬과 허용 스탯 ID에 추가하고, `GameInformation`의 7번째 스킬을 검증한다. 실행 JSON·스키마·예제·한국어 참고본·검증 스크립트의 스킬 목록을 함께 확장했다. 기존 여섯 ID와 순서는 유지한다.
2. **Progression:** `stat.attack.01` 이후 가넷 40개, 보스 0단계의 해금 노드 하나를 추가했다. 기존 `skill.cursorAura` 구매 ID를 새 펫에 부여하지 않는다.
3. **Combat:** `PetSkillController : IRunSkillController`, `PetBaseStat`, `PetRuntimeStat`을 추가했다. 대상 목록은 `MonsterCombatTarget.CollectActiveForRun`으로 재사용하고, 공격 사거리는 적의 피격 영역 기준으로 측정한다. 파란 폭발은 컨트롤러의 풀에서 한 번 재생·회수한다.
4. **App/씬:** 기존 BabyDragon 씬 인스턴스와 고리를 컨트롤러에 연결한다. 커서 앵커 연결 및 커서 추적·대기 거리 스탯은 제거했다. 성장 화면의 스킬 노드에는 BabyDragon 아이콘을 사용한다.
5. **문서:** `docs/skill-design.md`의 공통 자동 스킬 규칙을 따른다. v0.0.4의 자동 펫과 `skill.cursorAura`는 과거 기록이다.

## 탐색 비용

- 현재 대상이 유효하면 전체 적 목록을 다시 검색하지 않는다. 대상이 없을 때만 최대 초당 10회 스캔하며, 긴 프레임 뒤에 밀린 스캔을 반복 실행하지 않는다.
- 등록된 적 목록을 기존 재사용 `List`에 모으며, 스캔마다 배열·LINQ·새 목록을 만들지 않는다. 후보당 피격 영역 거리 계산은 한 번이며 커서 거리 계산은 없다.
- 거리 비교는 제곱 거리로 처리하고, 실제 이동이 필요한 경우에만 이동 거리의 제곱근을 구한다. 대상 유효성 검사는 거리 쿼리 없이 상태만 확인한다.
- `Physics2D.SyncTransforms`는 후보가 있는 스캔, 쿨타임이 끝나고 사거리 내로 판단된 공격의 시작 직전, 유효 대상의 명중 판정에 호출한다. 매 추적 프레임에는 동기화하지 않는다. 이펙트 풀과 반복 애니메이션·정렬 변경 시 갱신 방식을 유지한다. 단발 공격 애니메이션은 같은 이름이라도 매번 재생한다.

## 검증 기준

- 잠금 상태와 해금 상태에서 전투 입장·종료를 반복해 펫 표시가 정확하고 중복 인스턴스가 없는지 확인한다.
- 가까운 피격 영역 선택, 탐지 반경, 대상 소멸·무적·런 변경, 공격 사거리 경계, 여러 콜라이더를 가진 같은 적의 단일 피격을 확인한다.
- 공격 간격과 피해가 런 시작 스탯으로 고정되고, 펫 피해가 기존 치명타·보스 배율·처치·보상·DPS 경로에 한 번만 집계되는지 확인한다.
- 일시정지·시간 만료·포기·재시작과 이전 `RunId`의 늦은 명중이 피해를 만들지 않는지 확인한다.
- CombatSandbox의 고정 스냅샷으로 동작을 검증한 뒤 Main에서 Spine 애니메이션·정렬·실제 크기·커서 이동과의 독립성을 확인한다.
- 기존 자식 고리가 펫과 함께 나타나고 사라지는지, 파란 폭발이 매 명중마다 한 번만 재생되고 반복 잔류·누적되지 않는지 확인한다.

### 현재 검증
