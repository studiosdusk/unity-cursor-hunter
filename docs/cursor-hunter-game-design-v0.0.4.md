# CURSOR HUNTER · v0.0.4 기획서 · 최신 확정 반영본 (2026-09-18)
## 세부 기획 · 젬스톤 진행 · 전체 화면 설계

대상: Unity 2D / Steam PC / 마우스 커서 액션 성장 게임
목표: 약 2시간 30분 동안 커서 조작, 영구 특성 성장, 보스 돌파, v5 엔딩을 경험한다.

현재 Unity 특성 화면 프로토타입은 아래 진행 개정안을 기준으로 동적으로 구성한다.
스탯은 6개 행(공격력 10노드, 반경 11상태, 다중 클릭 5상태, 치명타 8상태,
젬 수집 6상태, 보스 공격력 5노드)으로 구성한다. 젬 수집은 사용자가 말한 5개
업그레이드 단계에 기본 상태를 더한 6개 상태이며, 해금·발견 확률 노드는 별도
노드로 연결한다. 스킬은 6종×4노드(해금 1 + 피해량·범위·쿨타임 강화 3), 몬스터는
`Monster1`~`Monster20` 해금 20종과 종별 생산량 강화 I/II/III 60개로 구성한다.
전리품은 일반 몬스터 20개·보스 5개를 확률 도감으로 두고, 펫은 1마리와 4개 강화
노드로 제한한다. 몬스터 표시명은 최종 디자인 확정 전까지
`Monster1`~`Monster20`으로 고정하며, 전투 원장의 외형 이름과 분리한다. 화면 데이터와
실제 연결 에셋은
[trait-ui-assets.md](collaboration/trait-ui-assets.md)에 기록하며, 표시 언어는 한국어를
기본으로 한다.

### 최신 확정 범위(요청 반영 단일 기준)

아래 표가 이 문서 전체에서 사용하는 현재 기획의 기준이다. 뒤쪽에 남아 있는 이전
수치나 예시가 이 표와 다르면 폐기된 참고 기록으로 보며, 구현·테스트·밸런스 표는
이 표를 우선한다.

| 영역 | 기본 상태 | 업그레이드 순서 | 최종 상태/규칙 |
|---|---|---|---|
| 공격력 | 공격력 1 | 1 → 3 → 6 → 10 → 16 → 24 → 35 → 50 → 70 → 100 | 10개 노드, 단계가 올라갈수록 증가폭 확대 |
| 반경 | 작은 원형 | 커서 영역 1~5 → 필드 1/32 → 1/16 → 1/8 → 1/4 반경 원형 → 화면 전체 | 기본 포함 11개 상태 |
| 다중 클릭 | 1회 클릭 | 더블 → 트리플 → 쿼드 → 자동 무한 클릭 | 8회·16회 노드와 별도 초당 클릭 분기는 없음 |
| 치명타 | 0% | 5% → 10% → 20% → 30% → 50% → 75% → 100% | 7개 확률 노드, 최종 100% |
| 젬 수집 | 젬에 커서를 닿게 한 뒤 클릭 | 접촉 자동 획득 → 자석 → 자석 확대 I → 자석 확대 II → 화면 전체 자동 수집 | 기본 포함 6개 상태 |
| 보스 공격력 | 보스 공격력 1 미해금 | 보스 공격력 1 → 2 → 3 → 4 → 5 | 보스 티어 조건을 충족한 뒤 해당 노드 구매 |

다중 클릭의 자동 무한은 한 번의 입력 묶음에 대한 자동 반복 기능이다. 이후 `초당
클릭 횟수`를 별도 Stat 가지로 늘리지 않는다. 반경은 UI 크기와 전투 판정 픽셀을
분리하고, 전체 화면 단계에서도 HUD 안전 영역과 실제 생성·판정 규칙은 전투 계약을
따른다. 모든 노드는 사용자가 원하는 행을 먼저 선택할 수 있으며, 같은 행의 선행
노드를 제외한 다른 Stat 행에는 강제 순서가 없다.

### 보스 구간별 Stat·젬스톤·스킬·몬스터 해금

2시간 30분 엔딩을 기준으로 각 구간의 구매 선택지를 열되, 첫 도전에서는 보스 HP를
넘기기 어렵고 반복 런과 자유로운 특성 순서로 후반에 돌파하도록 설계한다.

| 구간 | Stat 해금 범위 | 젬스톤/스킬 해금 | 몬스터 해금 |
|---|---|---|---|
| 시작 | 공격력 1~6, 반경 기본~영역 2, 치명타 5%, 젬 접촉 클릭·접촉 자동 | 가넷, 파이어볼 | Monster1 |
| v1 | 공격력 10~16, 반경 영역 3, 더블 클릭, 치명타 10%, 보스 공격력 1, 자석 | Stat에서 토파즈 해금, 라이트닝 볼트 | Monster2~Monster5 |
| v2 | 공격력 24, 반경 영역 4~1/32, 트리플 클릭, 치명타 20%, 자석 확대 I, 보스 공격력 2 | Stat에서 자수정·사파이어 해금, 프리즈닝·허리케인 | Monster6~Monster9 |
| v3 | 공격력 35, 반경 1/16, 쿼드 클릭, 치명타 30%, 보스 공격력 3, 자석 확대 II | Stat에서 다이아몬드 해금, 메테오 | Monster10~Monster13 |
| v4 | 공격력 50~70, 반경 1/8~1/4, 자동 무한, 치명타 50%·75%, 보스 공격력 4 | Stat에서 드래곤 젬 해금, 드래곤 브레스 | Monster14~Monster16 |
| v5 | 공격력 100, 화면 전체 반경, 치명타 100%, 보스 공격력 5, 화면 전체 자동 수집 | 최종 강화·엔딩 후 자유 성장 | Monster17~Monster20 |

젬스톤은 보스 처치 보상으로 자동 표시하지 않는다. 보스 티어가 열어주는 것은 해당
구간의 구매 접근권이며, 실제 젬스톤 슬롯과 랜덤 드롭 후보 추가는 `Stat → 젬 수집`
해금 노드를 구매한 뒤 다음 런부터 적용한다. 잠긴 젬스톤의 이름·아이콘·수량은
게임 시작·Main·전투 HUD에 미리 표시하지 않는다.

## 진행 개정안 · 2026-09-18

이 절의 노드 수·해금 시점·재화 비용은 아래 문서의 이전 프로토타입 수치를
대체한다. 목적은 2시간 30분 안에 `시작 → v1 → v2 → v3 → v4 → v5 엔딩`을
통과하면서 초반에는 보스를 못 잡고, 후반에는 일반 몬스터가 화면을 빠르게 채우는
성장 곡선을 만드는 것이다. 모든 구매는 다음 런부터 전투 스냅샷에 반영한다.

스테이지와 스킬을 열어 주며, 구매·드롭은 서로 다른 사건으로 저장한다.

### 보스·스킬 전투 밸런스 초안

아래 HP는 60초 보스 필드에서 초반에는 실패하고 다음 성장 묶음에서 돌파하도록
잡은 첫 기준값이다. 공격력·다중 클릭·스킬 강화가 실제로 연결되면 60초 런 로그의
실측 DPS를 기준으로 `balanceVersion`을 올려 조정한다. HP와 누적 피해는 `Int64`를
사용한다.

| 보스 | 초안 HP | 돌파 목표 상태 | 최초 처치 목표 시점 |
|---|---:|---|---:|
| v1 | 1,300 | 공격력 6~10, 더블 클릭, 파이어볼 | 20~45분 |
| v2 | 12,000 | 공격력 16~24, 트리플 클릭, 라이트닝 볼트 | 45~80분 |
| v3 | 180,000 | 공격력 35~50, 쿼드 클릭, 프리즈닝·허리케인 | 80~120분 |
| v4 | 18,000,000 | 공격력 70, 자동 무한, 메테오 | 120~150분 |
| v5 | 2,700,000,000 | 공격력 100, 자동 무한, 드래곤 브레스 | 150분 전후 |

### Stat 노드와 밸런스 초안

| 행 | 총 노드 | 값의 순서 | 추천 보스 구간 | 비용 예시(가넷 또는 행의 젬) |
|---|---:|---|---|---|
| 공격력 | 10 | 1, 3, 6, 10, 16, 24, 35, 50, 70, 100 | 시작, v1, v2, v3, v4, v5 | 0, 15, 30, 55, 90, 140, 210, 300, 420, 580 |
| 반경 | 11 | 작은 원 → 영역 1~5 → 1/32 → 1/16 → 1/8 → 1/4 → 전체 | 시작~v5 | 0, 12, 24, 42, 65, 95, 130, 185, 255, 350, 500 |
| 다중 클릭 | 5 | 1회 → 더블 → 트리플 → 쿼드 → 자동 무한 | 시작, v1, v2, v3, v4 | 0, 40, 90, 180, 360 |
| 치명타 | 8 | 0% → 5% → 10% → 20% → 30% → 50% → 75% → 100% | 시작~v5 | 0, 20, 40, 75, 120, 190, 300, 480 |
| 젬 수집 | 6 | 접촉 클릭 → 접촉 자동 → 자석 → 자석 I → 자석 II → 전체 자동 | 시작~v5 | 0, 35, 90, 150, 240, 420 |
| 보스 공격력 | 5 | 1 → 2 → 3 → 4 → 5 | v1~v5 | 각 단계 젬 25, 60, 110, 180, 300 |

보스 공격력의 화면 표시는 1~5 단계이며, 전투 계산에 적용할 초안 배율은 단계별
`+25% / +60% / +110% / +180% / +300%`로 둔다. 따라서 단계 ID와 내부 피해 배율을
분리해 저장하고, 보스 공격력 1을 구매했다고 일반 공격력이 바뀌지 않게 한다.

반경은 사용자가 요청한 미세 확대 1~5단계를 보존하면서 필드 비율 단계로 이어진다.
따라서 기본 작은 원형을 포함해 `작은 원형 → 영역 1~5 → 1/32 → 1/16 → 1/8 →
1/4 → 화면 전체`의 11개 상태를 사용한다. 다중 클릭은 1회에서 더블·트리플·쿼드
후 자동 무한으로 연결한다. 8회·16회 단계나 자동 무한 이후의 초당 횟수 Stat은
만들지 않는다. 반복 입력은 현재 다중 클릭 수를 각 입력 묶음마다 병렬 적용한다.

젬스톤은 다음 순서로 노출한다. 가넷은 시작부터 보이고, 토파즈(v1), 자수정(v2),
사파이어(v2), 다이아몬드(v3), 드래곤 젬(v4)은 Stat 해금 노드를 구매한 뒤에만
보유 패널과 랜덤 드롭 표에 추가한다. 각 종류에는 해금 1개와 발견 확률 강화 2개가
있다. 가중치는 `min(max, base + 발견 횟수×step)`으로 계산하고 해금된 종류의
합으로 100%를 다시 정규화한다. `드래곤 젬`은 여섯 번째 스킬 재화를 분리하기 위한
기획상 명칭이며, 원석 최종 이름은 아트 확정 때 바꿀 수 있다.

젬스톤 해금 비용은 직전 단계 젬스톤으로 결제한다(토파즈 해금은 가넷, 자수정은
토파즈, 사파이어는 자수정, 다이아몬드는 사파이어, 드래곤 젬은 다이아몬드).
해금 후 발견 I·II는 해당 젬스톤을 사용한다. 따라서 잠긴 재화가 필요한 노드는
생기지 않으며, 해금 직후 다음 런부터 그 젬스톤을 다시 투자할 수 있다.

### 전리품과 펫

전리품 탭은 구매 트리가 아니라 전투 중 확률로 획득하는 도감이다. 일반 Monster1~20
각각 1개와 보스 v1~v5 각각 1개를 둔다. 효과는 대상 피해 증가, 해당 몬스터 생산량
증가, 수확량 증가 중 하나로 배정하며, 보스는 반복 도전을 허용한다. 전리품 노드는
`acquisitionOnly`로 표시해 젬 비용 구매 버튼을 비활성화한다. 일반 전리품은 해당
몬스터 처치 시 확률로 판정하고, 보스 전리품은 보스 성공 정산에서만 확률로 판정한다.
같은 전리품을 다시 얻으면 도감 보유 수가 누적되거나 지정 효과의 중복 단계로
전환한다. 실패·포기 정산에서는 전리품을 지급하지 않는다.

| 전리품 그룹 | 개수 | 획득 사건 | 효과 후보 |
|---|---:|---|---|
| 일반 몬스터 전리품 | Monster1~20 각 1개 | 해당 종 처치 확률 | 대상 피해 증가 / 생산량 증가 / 수확량 증가 |
| 보스 전리품 | v1~v5 각 1개 | 보스 성공 정산 확률 | 보스 피해 증가 / 파훼 보너스 증가 / 보스 재화 수확량 증가 |

펫 탭은 커서 주변에 별도 판정 반경을 가진 자동 공격 펫 1마리로 시작한다. 펫 영역 I,
공격력 I, 공격 주기 I, 펫 영역 II의 4단계 강화만 제공해 2시간 30분 안에 체감할 수
있는 자동 보조로 제한한다. 펫은 처음부터 한 마리만 존재하고, 복수 펫 슬롯이나
펫 초당 횟수 분기는 만들지 않는다. 각 강화는 다음 런부터 적용한다.

| 펫 노드 | 효과 |
|---|---|
| 기본 펫 | 개별 커서 반경으로 자동 공격 1마리 |
| 펫 영역 I | 펫 판정 반경 증가 |
| 펫 공격력 I | 펫 피해 배율 증가 |
| 펫 공격 주기 I | 펫 자동 공격 간격 감소 |
| 펫 영역 II | 펫 판정 반경 추가 증가 |

## 00. 게임 개요와 핵심 루프

플레이어는 화면의 몬스터 위로 커서를 옮긴 뒤 좌클릭하여 공격한다. 최초에는 작은 원형 커서와 단일 타격으로 시작한다. 보스를 처치할수록 새로운 몬스터·스킬이 열리고, 특성 트리에서 원하는 가지를 골라 공격 범위·타격 수·자동화를 성장시킨다. 젬스톤 종류는 Stat의 해금 노드를 구매한 뒤 랜덤 드롭 표에 추가된다.

```text
게임 실행 → 첫 설정 → 무료 연습 → 60초 일반 Field
→ 일반 정산 → 특성 구매 → 일반 Field 반복
→ 보스 선택 → 60초 보스 Field → 파훼 성공/실패
→ 보스 정산 → 새 해금 → 다음 보스
→ v5 최초 처치 → 엔딩·크레딧 → 엔딩 이후 자유 성장
```

일반 Field에서는 해금한 모든 몬스터가 주기와 무작위 위치에 따라 함께 등장한다. 몬스터가 죽으면 해당 보상이 런 기록에 즉시 들어가고, 젬스톤 형체가 HUD 슬롯으로 0.35~0.65초 동안 이동한다. 이동 연출이 끝나기 전에 화면을 바꾸어도 지급 수량은 변하지 않는다.

## 01. 화면 기준과 공통 UI

- 전투 기준 해상도는 1920×1080, 최소 지원 레이아웃은 1280×720, 모든 화면은 16:9 전투 영역을 유지한다.
- 전투 외곽 32px, 상단 HUD 160px, 하단 안내 96px은 몬스터 생성 영역에서 제외한다.
- 일반·보스 Field는 타이머를 좌측 상단, 젬스톤 HUD를 우측 상단, 보스 HP를 그 아래 두 번째 행에 둔다.
- 특성 화면은 좌측 상단 `스탯 / 스킬 / 몬스터 / 전리품 / 펫` 탭, 좌측 중단 젬스톤 보유 목록, 우측 상단 현재 특성 요약, 중앙 노드 체인 목록, 우측 선택 상세 영역, 하단 뒤로·초기화 영역을 고정한다. 스탯은 카테고리마다 한 행, 스킬은 스킬 종류마다 한 행으로 나열하고 인접 노드를 선으로 연결한다. 몬스터는 해금 20종과 생산량 60단계를 두 행으로 연결하며 가로 스크롤을 사용한다.
- Main은 일반 Field 배경을 사용하는 정적 메뉴다. 중앙 메뉴는 텍스트와 hover 밑줄로 표시하며, 전투 HUD를 그리지 않는다.
- 텍스트 버튼의 실제 클릭 영역은 최소 160×48px이다. hover 밑줄, 키보드 포커스 테두리, 잠금 사유를 함께 표시한다.
- 시스템 팝업·메뉴·보스 파훼 표식·전투 순서로 입력 우선순위를 둔다. 팝업을 닫은 클릭은 다음 화면의 공격으로 전달하지 않는다.
- ESC, 창 포커스 상실, Steam Overlay는 전투·타이머·스킬·파훼를 함께 멈춘다. `계속`을 새로 입력해야 재개한다.

## 02. 젬스톤 해금과 표시

### 표시·획득 규칙

| 진행 상태 | 표시·획득 가능한 젬스톤 | 해금 사건 |
| --- | --- | --- |
| 게임 시작 | 가넷 | 최초 저장 생성. 가넷 가중치 70 |
| 토파즈 노드 구매 후 | 가넷, 토파즈 | `stat.gemstone.unlock.topaz` 구매. 기본 가중치 20 |
| 자수정 노드 구매 후 | 가넷, 토파즈, 자수정 | `stat.gemstone.unlock.amethyst` 구매. 기본 가중치 8 |
| 사파이어 노드 구매 후 | 가넷, 토파즈, 자수정, 사파이어 | `stat.gemstone.unlock.sapphire` 구매. 기본 가중치 3 |

가넷은 시작 특성·공격력·일반 보상의 기본 재화다. 토파즈·자수정·사파이어·다이아몬드·드래곤 젬은 각각 고유한 색상 재화이며 Stat 해금 구매 후 일반·보스 드롭 표에 참여한다. 발견 노드는 해당 종류의 가중치만 올린다.

### 표시 규칙

1. 새 게임과 무료 연습에서는 가넷 슬롯 하나만 렌더링한다. 잠긴 젬스톤의 이름·아이콘·0 수량·빈 슬롯을 그리지 않는다.
2. `Stat → 젬 수집`의 해금 노드를 구매한 순간 다음 런부터 해당 젬스톤 슬롯을 추가한다. 새 슬롯은 0에서 시작하며 이전 런에 소급하여 보상을 만들지 않는다.
3. 일반 Field, 보스 선택, 보스 Field, 일반·보스 정산, 특성 화면은 현재 해금된 젬스톤만 보여준다. 슬롯은 항상 우측 또는 좌측 목록의 안쪽부터 채운다.
4. Main 최상위 메뉴, Splash, 첫 설정, 일시정지, 설정, 기록, 저장·복구 팝업, 엔딩·크레딧에는 젬스톤 보유 HUD를 두지 않는다.
5. 보스 선택에서 아직 잠긴 보스의 보상은 `잠긴 보상`으로 표시한다. 해금되지 않은 젬스톤의 명칭·수량을 미리 노출하지 않는다.
6. 특성 구매 상세는 필요한 재화가 해금된 경우에만 이름과 수량을 표시한다. 잠긴 재화는 `Stat에서 젬스톤 해금` 안내로 표현한다.
7. 젬스톤 형체가 HUD로 이동하는 연출은 읽기 위한 시각 피드백이며, 런 보상·저장·정산의 지급 시점은 몬스터 사망 시점이다.

### 젬스톤 UI

전투·보스 선택·정산 HUD는 우측 상단에 해금된 종류를 오른쪽으로 정렬한다. 각 슬롯은 젬스톤 색상·이름·보유 수량·이번 판 증감을 표시한다. 특성 화면은 같은 목록을 좌측 중단 세로 카드로 표시한다. 수량은 999,999까지 그대로 표시하고 그 이상은 축약 표기와 툴팁의 정확한 정수를 함께 사용한다.

해금된 젬스톤의 등장 확률은 다음 식으로 계산한다.

`W(type) = min(maxWeight, baseWeight + 발견 강화 횟수 × stepWeight)`

`P(type) = W(type) / ΣW(해금된 type) × 100`

현재 기준값은 가넷 `70/0`, 토파즈 `20/+5`, 자수정 `12/+4`, 사파이어 `8/+3`,
다이아몬드 `4/+2`, 드래곤 젬 `2/+1`이며 각 희귀 젬스톤에는 발견 강화 노드 2개가 있다. 잠긴 종류의
가중치는 0으로 취급하고 이름·아이콘·수량도 그리지 않는다. 드래곤 젬은 v4 이후
드래곤 브레스의 전용 재화다.

## 03. 커서 공격과 전투 종료

- 최초 공격력 A=1, 커서 반경은 작은 원, 좌클릭 누름 1회가 한 공격 묶음이다. 커서와 몬스터 판정 원이 겹친 살아 있는 적 모두에게 피해를 준다.
- 이동·홀드만으로는 공격하지 않는다. 수동 공격은 초당 최대 8묶음, 기준 조작 속도는 초당 2클릭이다.
- 더블·트리플은 같은 대상 목록에 같은 시각 2/3회 타격한다. 첫 타격으로 죽은 대상의 남은 타격은 소멸하고 다른 대상에 전달하지 않는다.
- 자동 무한 클릭은 마지막 다중 클릭 노드다. 별도의 초당 클릭 횟수 강화 가지는 두지 않으며, Combat은 자동화 타격 간격을 내부 고정 밸런스 값으로만 관리한다.
- 일반 Field와 보스 Field의 기본 제한 시간은 60초다. 정확히 만료한 시각의 공격·생성·파훼는 무효이며, HP가 0이 된 시각에는 즉시 성공 처리를 시작한다.
- 일반 Field 시간 종료는 생존 적을 보상 없이 제거하고 확정 처치 보상을 지급한다. 보스 시간 초과와 중도 포기는 기본·파훼 보상 모두 0이다.
- 실측 DPS는 실제 HP 감소량을 정지 시간을 뺀 전투 경과 시간으로 나눈다. 과잉 피해는 제외하고 스킬 피해는 포함한다.

## 04. 일반 Field

- Monster1은 시작부터 등장한다. 이후 해금한 종은 고유 주기로 계속 함께 등장하며 교체·비활성화하지 않는다.
- t=0에 첫 무리를 생성하고 t=60에는 생성하지 않는다. 무리 중심은 HUD를 제외한 영역에서 무작위로 고르며 80px 안에 배치한다.
- 상단 160px·하단 96px·좌우 32px을 생성 금지 영역으로 둔다. 위치는 최대 8회 탐색하며 실패한 개체는 건너뛴다. 생존 상한을 넘는 생성은 누적하지 않는다.
- 종별 생성 기회는 라운드로빈으로 순환한다. 몬스터끼리 겹침은 허용하고, 종별 실루엣·색상·피격 이펙트로 구분한다.
- 피격 HP 바는 1초 표시한다. 처치 시 종별 보상 수량을 런 기록에 더하고, 해금된 젬스톤 형체를 해당 HUD 슬롯으로 보낸다.
- 남은 10초부터 타이머·경고음을 강조한다. 0초에 전투·생성을 멈추고 생존 적을 Fadeout한 뒤 0.4초 후 일반 정산으로 이동한다.

## 05. 보스 Field와 파훼

보스 Field에는 일반 몬스터가 없다. 보스 HP 바는 화면 상단에 가로로 길게 표시하며, 보스의 현재 HP·남은 시간·예약 보너스를 동시에 보여준다. 기본 공격과 스킬은 보스에게 피해를 주지만 자동 공격이나 스킬이 파훼 표식을 대신 처리하지 않는다.

| 보스 | HP | 예고 / 입력 | 실패 시 시간 차감 | 최초 처치 해금 |
| --- | ---: | --- | ---: | --- |
| 보스 v1 | 1,300 | 표식 1개 / 2.0초 | 3초 | 더블·Monster2~5·파이어볼 |
| 보스 v2 | 12,000 | 표식 2개 순서 / 2.0초 | 4초 | 트리플·Monster6~9·라이트닝 볼트 |
| 보스 v3 | 180,000 | 표식 2개 순서 / 1.8초 | 5초 | 쿼드·Monster10~13·메테오 |
| 보스 v4 | 18,000,000 | 표식 3개 순서 / 1.8초 | 6초 | 자동 무한·Monster14~16·드래곤 브레스 |
| 보스 v5 | 2,700,000,000 | 표식 3개 순서 / 1.6초 | 7초 | 치명타 100%·Monster17~20·엔딩 |

예고 중에는 외곽 윤곽만 표시하고, 입력 창에는 번호·닫히는 링·남은 시간을 표시한다. 번호를 순서대로 좌클릭하면 이벤트 1회 성공, 잘못된 클릭은 진행하지 않으며 창 종료 시 1회 실패한다. 성공할 때마다 처치 시 보너스 5%를 예약하고 최대 25%까지 누적한다. 실패는 남은 시간을 차감하며 보너스는 유지한다. 보스가 먼저 죽으면 진행 중 파훼 이벤트를 취소하고 성공 정산으로 이동한다.

## 06. 특성 화면과 자유 분기

스탯·스킬·몬스터·전리품·펫 탭은 좌측 상단에 고정한다. 화면은 일반 전투에서 사용하는 필드
텍스처를 전체 배경으로 깔고, 가독성을 위해 짙은 남색 오버레이를 한 겹 적용한다.
아이콘별 장식 테두리나 원형 프레임은 사용하지 않으며, 모든 특성 노드는 동일한
정사각형 셀로 표시한다. 젬스톤 보유량과 현재 특성 요약은 상단에 고정하고, 중앙
목록은 카테고리별 한 행 체인으로 배치한다. 스탯·스킬·전리품·펫은 세로 스크롤하고,
몬스터 해금·생산량 체인은 가로 스크롤한다. 각 행의 인접 요소는 흰색에 가까운 런타임 선으로
연결하며 행 내부 별도 카테고리 버튼이나 팬·줌 입력은 사용하지 않는다.

공통 시작점은 무료다. 공격력·반경·다중 클릭·치명타·젬 수집·보스 공격력 가지는
서로 독립적으로 선택할 수 있다. 젬스톤 해금·발견 노드 내부에는 다음 해금 순서를
읽기 위한 선행 조건이 있다. 자동 무한 클릭 이후 별도의 초당 속도 가지는 두지 않는다.

노드 상태는 완료, 구매 가능, 재화 부족, 보스 잠금을 사각 셀 색상·작은 상태 아이콘·
문장으로 구분한다. 회색 잠금 테두리는 사용하지 않는다. 노드 선택은 상세 패널을
갱신하고, 현재 프로토타입의 `강화` 버튼은 저장·전투 계약을 연결하기 전까지 로컬
미리보기 상태만 변경한다.

젬스톤은 `Stat → 젬 수집` 행에서 해금한다. 시작 시에는 가넷만 표시하고,
`토파즈 해금 → 자수정 해금 → 사파이어 해금 → 다이아몬드 해금` 순서의 노드를
구매할 때마다 다음 종류를 랜덤 드롭 표에 추가한다. 아직 해금되지 않은 젬스톤의
이름·아이콘·수량은 보유 패널에 표시하지 않는다. 발견 I·II 노드는 해당 종류의
가중치를 올리고, 목록 행에 현재 정규화 확률을 표시한다.

## 07. 성장·인플레이션 기준

이 절은 2시간 30분 엔딩을 위한 밸런스 초안이다. 수치는 첫 플레이테스트에서
`balanceVersion`을 올리며 조정한다. HP·피해·재화·누적 처치는 Int64로 저장하고,
오래된 30레벨 공격력 원장과 대표 몬스터 이름은 사용하지 않는다.

공격력은 각 노드 사이의 증가폭이 일정하지 않으며, 후반 노드일수록 폭발적으로
커진다. 공격력 노드는 다른 Stat 행과 독립적으로 구매할 수 있고, 구매 결과는 다음

### 일반 몬스터 물량

Monster1~Monster20의 HP·젠 주기·특징·해금·생산량 강화는 `B02` 원장을 단일 기준으로
사용한다. 해금한 낮은 티어 몬스터를 교체하지 않고 후반에도 계속 생성한다. 생산량
I/II/III은 `×1.25 / ×1.50 / ×1.75`이며, 종별·전체 상한을 넘은 생성은 누적하지
않는다. 목표는 후반에 화면을 채우는 물량 쾌감과 새 몬스터의 HP·이동 특징을 동시에
유지하는 것이다.

### 스킬·타격 연출

스킬 6종과 기본 피해·범위·쿨타임·3단계 강화는 `B03`을 단일 기준으로 사용한다.
성장 단계마다 기본 타격 이펙트의 형태·색상·크기를 바꾸며, 휘두르는 궤적이나 검기
연출은 사용하지 않는다. 파이어볼·라이트닝·프리즈닝·허리케인·메테오·드래곤 브레스의
피해와 쿨타임은 기본 공격력 A와 별도 계수로 계산하고, 스킬이 보스 파훼를 대신하지
않는다.

### 보스·플레이 타임 검증

v1~v5 HP는 상단 보스 표의 1,300 / 12,000 / 180,000 / 18,000,000 /
2,700,000,000을 시작값으로 사용한다. 초반 보스는 초기 빌드로 실패할 수 있고,
반복 일반 런에서 Stat·Skill·전리품·펫을 선택한 뒤 후반에 돌파하는 흐름을 목표로
한다. 각 보스는 반복 도전할 수 있으며, 실패·포기 보상은 0이다.

## 08. 정산·엔딩·설정

일반 정산은 젬스톤 종류별 이번 판 수량·최종 지급량, 종별 처치 수, 실측 DPS, 전투 시간, 다음 목적지를 표시한다. 보스 성공 정산은 기본 보상과 파훼 보너스를 분리하고 최초 처치 해금(보스·스킬·몬스터)을 함께 보여준다. 젬스톤은 Stat 해금 노드로 추가하므로 해당 화면에는 특성으로 이동하는 안내만 표시한다. 보스 실패 정산은 보상 0, 남은 HP, 실패 횟수와 차감 시간, 다음 성장 버튼을 표시한다.

v5 최초 처치 후 엔딩 플래그를 저장하고 평원이 회복되는 20초 내외 연출과 크레딧을 실행한다. 엔딩 후 Main에서는 일반 Field, 보스 반복, 특성, 기록, 엔딩 다시 보기를 계속 제공한다. 엔딩 이후에는 남은 Stat·Skill·Monster·전리품·펫 노드를 선택 성장으로 제공한다.

설정은 오디오, 화면, 입력·가독성, 데이터 탭으로 구성한다. 해상도·UI 배율·효과 강도·화면 흔들림·자동 단축키·언어·저장 복구·초기화를 제공한다. 전투 진행과 보스 해금은 로컬 저장과 백업 3세대에 기록하고, 구매·정산은 한 번만 지급되도록 정산 ID를 사용한다.

## 09. 전체 상태 목록

S01~S48은 최초 실행, 일반 Field, 보스, 특성, 설정, 저장 오류, 엔딩을 하나의 화면 상태 카탈로그로 정의한다. 각 상태 페이지는 진입 조건, 표시 정보, 행동, 전환, 예외·복귀를 포함한다. 화면 아래 이동 링크는 문서 내 탐색용으로 사용한다.

## B01. 공격력 · 특성 노드 원장(통합 기준)

### 공격력·반경·다중 클릭·치명타·젬 수집·보스 공격력

이전 30레벨/8회/16회 확장안은 폐기한다. 현재 원장은 상단의 `최신 확정 범위`와
아래 표를 그대로 사용한다. 공격력 값은 기본 공격력 1에서 시작하며, 다음 노드로
갈수록 증가폭이 커진다. 비용은 테스트용 초안이고, `balanceVersion`별 런 로그를
확인한 뒤 조정한다.

| 행 | 상태·노드 순서 | 상태 수 | 구간별 최초 구매 가능 |
|---|---|---:|---|
| 공격력 | 1 → 3 → 6 → 10 → 16 → 24 → 35 → 50 → 70 → 100 | 10노드 | 시작 / v1 / v2 / v3 / v4 / v5 |

개선한다. 보스 공격력 노드는 보스 티어를 충족한 뒤 원하는 시점에 구매할 수 있다.

각 강화는 피해량 `+35%`, 범위 `+30%`, 쿨타임 `-20%`를 기본 초안으로 한다.
드래곤 브레스는 마지막 스킬이며 피해량·범위·연출 모두 가장 강하게 구성한다.
스킬은 보스 파훼를 대신하지 않고, 파훼 입력과 전투 시계는 별도로 처리한다.
자동 발동 스킬의 과밀을 막는 최소 간격은 Combat 런타임이 별도로 제한한다.

## B04. 보스 HP · 목표·보상(전투 플레이테스트 전 초안)

### 보스 수치 원장

| 보스 | HP / 시간 | 권장 공격 상태 | 기본 처치 보상 | 누적 첫 처치 목표 |
| --- | --- | --- | --- | --- |
| v1 | 1,300 / 60초 | 공격력 6~10, 더블, 파이어볼 | 가넷100 + 토파즈20 | 20~45분 |
| v2 | 12,000 / 60초 | 공격력 16~24, 트리플, 라이트닝 볼트 | 가넷2,000 + 토파즈35 + 자수정20 | 45~80분 |
| v3 | 180,000 / 60초 | 공격력 35~50, 쿼드, 프리즈닝·허리케인 | 가넷50,000 + 자수정50 + 사파이어15 | 80~120분 |
| v4 | 18,000,000 / 60초 | 공격력 70, 자동 무한, 메테오 | 가넷2,000,000 + 사파이어40 + 다이아몬드5 | 120~150분 |
| v5 | 2,700,000,000 / 60초 | 공격력 100, 자동 무한, 드래곤 브레스 | 가넷50,000,000 + 사파이어60 + 다이아몬드15 | 150분 전후 |

UI는 만/억 단위로 축약하고 툴팁에 정확한 정수 수치를 표시한다. 보스v5 HP는 27억으로 32비트 부호 정수 범위를 초과하므로 HP·누적 피해·재화는 64비트 정수를 기준으로 한다.

기본 보상은 첫 처치와 반복이 같고 최초에는 해금 플래그만 추가한다. 성공 n회 보너스는 보석별 floor(기본×0.05×min(n,5)). 실패는 기본·보너스 모두 0. 보스 v5는 바로 엔딩 조건이며, 엔딩 이후의 추가 노드는 선택 보상으로 두어 필수 2시간 30분을 늘리지 않는다.

### 실패→성장→돌파

다음 보스는 직전 보스 처치 후 즉시 도전할 수 있다. 처음에는 화력 부족을 경험하고 정산에서 ‘공격력 성장 후 재도전’을 안내한다. 자동 잠금이나 필수 실패 횟수는 없다. 실력과 구매 순서에 따라 조기 처치도 허용한다.

- 시작 공격력 6~10·단일 클릭으로 v1을 처음에는 놓칠 수 있게 한다.
- v1 직후 공격력 16~24·더블로 v2를 재도전한다.
- v2 직후 공격력 35~50·트리플/쿼드로 v3를 노린다.
- v3 직후 공격력 70·자동 무한으로 v4를 노린다.
- v4 직후 공격력 100·드래곤 브레스로 v5를 150분 전후에 돌파한다.



엔딩·크레딧·재실행의 상세 흐름은 S31~S33을 따른다.

## B05. 파훼 주기 · 보상 확정


### 패턴

| 보스 | 첫 발생·반복 주기 | 예고 / 입력 창 | 직접 입력 | 실패 차감 |
| --- | --- | --- | --- | --- |
| v1 | 10초 / 10초 | 0.6초 / 2.0초 | 원형 표식 1개 클릭 | 3초 |
| v2 | 9초 / 9초 | 0.6초 / 2.0초 | 표식 2개 순서대로 | 4초 |

| v5 | 7초 / 7초 | 0.5초 / 1.6초 | 표식 3개 순서대로 | 7초 |

주기는 실제 전투 경과 시간 기준이다. 시간 차감으로 패턴이 빨라지지 않는다. 보스는 패턴 중에도 무적이 아니며, 표식은 보스 외곽 160~260px 범위의 안전 영역에 둔다. 표식 반경 32px, 표식 사이 최소 80px. 보스 뒤에 숨지 않도록 최상단 전투 레이어에 표시한다.

입력 창 전체에서 표식을 순서대로 누르면 1회 성공. 잘못된 클릭은 진행하지 않고 짧은 피드백만 주며, 창이 끝나면 이벤트당 1회 실패 처리한다. 성공하면 표식 제거와 ‘처치 시 보너스 +5%’를 표시한다. 보너스는 보스 기본 보석 각 종류에 +5%, 최대 5회/25%; 종류별 내림한다. 시간 연장·추가 피해는 없다. 처치 시 진행 중인 이벤트는 취소하며 실패를 부과하지 않는다.

## B06. 물량 · 재화 공급 · 시간 예산

Monster1~Monster20의 기본 HP·젠 주기·특징은 `B02`를 단일 원장으로 사용한다.
최고 보스 진행도가 올라가도 해금된 낮은 티어 몬스터를 제거하지 않는다. 생산량
강화 I/II/III과 동시 상한을 함께 적용해 후반에 화면을 빠르게 채우되, 매 프레임마다
전체 몬스터를 복사하거나 파일을 저장하지 않는다.

| 구간 | 누적 목표 | 일반 Field 체감 | 일반 런·보스·특성 예산 |
|---|---:|---|---:|
| 시작 | 0~20분 | Monster1 위주, 단일 클릭과 작은 원 | 조작 학습·초기 특성 |
| v1 | 20~45분 | Monster1~5 중첩, 더블 클릭 | 첫 보스 실패 가능·토파즈 접근 |
| v2 | 45~80분 | Monster1~9 물량 증가 | 트리플·스킬 2~4종·자수정/사파이어 |
| v3 | 80~120분 | Monster1~13, 순간이동·분리 | 쿼드·메테오·다이아몬드 |
| v4 | 120~150분 | Monster1~16, 자동 무한과 대량 처치 | 드래곤 브레스·드래곤 젬 |
| v5 | 150분 전후 | Monster1~20, 화면 물량과 최종 보스 | 치명타 100%·화면 전체·엔딩 |

각 일반 Field는 60초다. 공급량은 `생성 묶음 × 생산량 배율 × 해금 종 수`로
추정하되, 종별 상한·전체 상한·판정 가능한 화면 면적을 넘으면 생성을 누적하지
않는다. 보스 HP는 v1 1,300 / v2 12,000 / v3 180,000 / v4 18,000,000 /
v5 2,700,000,000에서 시작한다. 실제 플레이타임이 150분을 넘거나 엔딩 이전에
특성 구매가 멈추면 비용·젠 주기·보스 HP 중 하나만 `balanceVersion`으로 조정하고,
동시에 여러 축을 바꾸지 않는다.

약 2시간 30분은 모든 가지를 순서대로 구매하는 제한이 아니라 기준 빌드의 목표다.
공격 우선·반경 우선·재화 우선처럼 사용자의 구매 순서가 달라도 v5 엔딩에 도달할
수 있어야 하며, 보스 실패 후 일반 Field 재도전과 특성 구매가 항상 가능해야 한다.

### 재화 접근 경로

v1은 토파즈 해금 노드와 더블·라이트닝·Monster2~5, v2는 자수정/사파이어와
트리플·프리즈닝/허리케인·Monster6~9, v3은 다이아몬드와 쿼드·메테오·Monster10~13,
v4는 드래곤 젬과 자동 무한·드래곤 브레스·Monster14~16, v5는 최종 반경·치명타·
보스 공격력과 Monster17~20을 제공한다. 토파즈·자수정·사파이어·다이아몬드·드래곤
젬은 보스 보상 슬롯으로 자동 추가하지 않고 Stat의 해금 노드 구매로 접근한다.
구매 이후에만 얻는 재화를 요구하는 순환 잠금은 없다.

## B07. 타격 연출 · 가독성 예산

### 공격 성장의 시각 언어

| 조건 | 형태·색상 | 크기·지속 | 가독성 규칙 |
| --- | --- | --- | --- |
| 초기 | 흰 점 + 작은 원형 파편 | 판정 반경×1.0 / 0.08초 | 타격 지점 고정 |
| 더블 구매 | 황금 이중 링 | 반경×1.1 / 0.10초 | 2타 숫자 묶음 |
| 트리플 구매 | 보라 삼각 파편 + 3중 점 | 반경×1.15 / 0.12초 | 3타 표시 |
| 자동 무한 클릭 | 청색 맥동 링 | 반경×1.2 / 0.12초 | 0.1초 단위 연출 합산 |
| v5 처치 | 흰 결정 문양 + 화염 점 | 반경×1.0 / 0.15초 | 표식보다 낮은 레이어 |

이 단계는 별도 무기 아이템 대신 공격 성장의 시각 등급이다. 이펙트 크기는 연출 전용이며 피해 반경은 범위 특성 R만 따른다. 휘두르는 궤적·검기는 쓰지 않는다. 숫자·링 합산은 논리적 타격 수와 재화 수량을 줄이지 않는다.



일반 피격 숫자는 적당0.1초 묶음, 화면동시숫자60개, 보석연출60개, 충돌연출100개를 표시 상한으로 둔다. 흡수음은0.1초당1회, 타격음은동시8보이스로제한하고이상한큰음량을만들지않는다. 표식입력음은전투음보다우선한다. 성능저하에서는파티클·숫자부터줄이고적체력·보상·타격판정은바꾸지않는다.

충족하면 원하는 순서로 선택할 수 있다. 현재 UI 프로토타입의 `강화`는 로컬 미리보기
