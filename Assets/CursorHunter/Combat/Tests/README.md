# Combat/Tests
담당: 친구.
용도와 연결 규칙: 프로젝트 루트 docs/collaboration/architecture.md 및 contracts.md.
씬·프리팹·데이터 인스턴스는 담당자가 Unity 6000.3.13f1에서 생성한다.

`CursorHitEffectTests`는 고정 런 스냅샷과 실제 ParticleSystem을 사용한다. 공유 시스템 4개,
월드 위치/크기/수명, 스킬·오래된 런 제외, 1만 요청의 총량 제한과 재사용, 랜덤 4종과 연속
중복, 준비 후 타격 경로의 관리 힙 할당, 정지/재개/구독, 처치 전 몸체 좌표, 이동 경로·중복
콜라이더·대상 쿨타임·시간 만료, 전투/Unity 난수 분리를 검사한다.
0번을 제거한 3종, 단일 종류, 중간 빈 항목, 4개 초과, 전체 빈 목록도 검사한다.
유효한 종류만 재생하는지와 개수 변경 후 관리 힙 할당·정지·재개·종료 동작을 함께 확인한다.
재질 Override 생략과 이전 두 배열의 일회성 마이그레이션, 삭제한 목록의 재생성 방지도 확인한다.
`DamageTextTests`는 별도로 유지하며 확장된 피해 이벤트가 기존 숫자 표시에 영향을 주지 않는지 확인한다.

PlayMode 어셈블리의 `CursorHitEffectPlayModeTests`는 Sandbox를 실제 실행해 8개 타격의
표시, 파티클 시간 정지, 비활성화 시 즉시 제거, 재활성화 후 구독 1회, 종료 시 제거를 검증한다.
Inspector 직렬화 변경으로 6개 추가·3개 재정렬·전체 삭제·1개 복구·빈 항목을 섞은 목록을
실행 중 적용하고, 일시정지/비활성 상태 및 이전 시스템 제거·중복 구독도 검증한다.
그래픽 장치가 있는 실행에서 `CURSOR_HIT_CAPTURE_PATH` 환경 변수에 PNG 출력 경로를
지정하면 Sandbox 카메라의 렌더링 결과도 저장한다.
