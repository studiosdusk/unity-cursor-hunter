용도와 연결 규칙: 프로젝트 루트 docs/collaboration/architecture.md 및 contracts.md.

범위 확대, 목록 재정렬, 잘못된 ID, 숨겨진 커서, Inspector 선택과 반경 변경,
잘못된 렌더러 연결의 거부를 EditMode에서 검증한다.
