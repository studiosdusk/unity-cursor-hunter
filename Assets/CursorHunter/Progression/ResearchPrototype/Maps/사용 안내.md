# 연구 맵 에디터 사용 안내

## 열기

Unity 상단 메뉴에서 **Tools → Cursor Hunter → 연구 맵 에디터**를 선택합니다. 처음 열면 기존 Main 씬에서 가져온 `v1`이 표시됩니다. Main 씬을 직접 수정한 이후라면 Main 씬을 열고 **씬에서 가져오기**를 눌러 현재 상태로 새 버전을 만들 수 있습니다.

## 노드와 연결 만들기

1. 맵 빈 공간을 우클릭하고 **빈 노드 생성**을 누릅니다.
2. 빈 노드를 우클릭하고 **연구 주입**에서 원하는 연구를 선택합니다. 노드를 클릭한 뒤 오른쪽의 **연구 종류**에서도 선택할 수 있습니다.
3. 레벨마다 젬스톤과 비용을 입력합니다. 같은 재화를 모든 레벨에 적용하거나, 입력한 비용을 복사해 붙여넣을 수 있습니다. 무료는 재화를 선택하고 비용을 0으로 입력합니다.
4. 선행 노드를 우클릭하고 **다른 노드에 연결**을 누른 다음 후행 노드를 클릭합니다. 연결 취소는 Esc를 누릅니다.
5. 후행 노드를 선택해 필요한 선행 노드 수를 정합니다. 선행 노드는 각각 1레벨 이상 구매하면 충족됩니다.
6. **저장**을 누릅니다. 자동으로 검증하고 문제가 없으면 Main 씬에 적용해 맵 버전과 씬을 함께 저장합니다. 문제가 있으면 오류 목록에서 해당 노드와 수정할 내용을 확인한 뒤 다시 저장합니다.

Main 씬이 열려 있지 않으면 저장할 때 잠시 열어 적용한 뒤 닫습니다.

노드는 드래그로 이동하거나, 노드를 클릭한 뒤 오른쪽 **위치**의 X·Y 좌표를 직접 입력할 수 있습니다. 맵의 빈 공간을 드래그하거나 마우스 가운데 버튼으로 맵을 이동하고, 휠로 확대·축소할 수 있습니다. 노드를 우클릭하면 복제하거나 삭제할 수 있습니다. 노드를 복제하면 새 ID가 부여됩니다. 버전 복제는 기존 노드 ID를 유지합니다.

## 버전과 씬

- **버전 복제**로 기존 구성에서 새 버전을 만듭니다. 버전 이름과 설명은 오른쪽에서 바꿉니다.
- 연구 맵 버전의 위치·연결·비용을 씬에 적용합니다. 씬의 노드 오브젝트도 직접 선택하고 이동할 수 있습니다.
- 저장할 때 열린 Main 씬도 함께 저장하므로, 씬에서 작업 중인 다른 변경사항도 같이 저장됩니다.
- 에디터에서 적용한 이후 씬을 직접 수정했다면 먼저 **씬에서 가져오기**로 변경된 구성을 새 버전에 보관해야 합니다. 가져오기는 씬 변경을 저장하지 않으므로 Unity에서 씬도 저장해 주세요.
- 기존 구매 기록의 이전 정책이 아직 없어 **기존 노드 삭제, 기존 노드의 연구 종류 변경, 기존 노드의 선행 조건 변경**은 씬에 적용할 수 없습니다. 새 노드 추가와 새 노드에 대한 연결, 위치와 비용 변경은 사용할 수 있습니다.
- `v2 전체 노드 테스트`는 별도의 테스트 배치 ID와 무료 비용을 사용합니다. 저장하면 기존 노드·연결선을 씬 내부에 보관하고 테스트 맵으로 전환합니다. 필요한 경우 현재 맵의 자동 보관 버전이 만들어지며, 테스트 후 기존 버전 또는 그 보관 버전을 선택하고 저장하면 복원됩니다.
- 현재 구입 기록에는 맵 버전과 당시 지불한 비용이 저장되지 않습니다. 출시 후 버전 변경과 환불 정책은 별도 구현이 필요합니다.
- 기존 씬은 변환 전 SO에 남아 있는 기존 비용으로 동작합니다. 에디터로 씬에 적용한 노드는 배치별 비용을 사용합니다. SO에 남은 기존 비용은 모든 씬의 전환이 끝나기 전까지 호환용으로 유지됩니다.

연구 이름과 효과 설명은 `Assets/CursorHunter/Data/Authoring/ResearchText.xlsx`에서 수정합니다. 효과 수치와 아이콘은 연구 SO에서 관리합니다. 과거 맵 버전은 SO와 엑셀을 참조하므로, 이 원본을 수정하면 과거 버전의 효과나 문구도 바뀔 수 있습니다.
