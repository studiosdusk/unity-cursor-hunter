# 연구 노드 데이터

`cursor.*.asset`은 현재 테스트 맵에서 사용하는 6종의 `ResearchDefinition`이다. SO는 노드의 종류를 정의하며, 맵 위의 위치나 연결은 담지 않는다.

- `stableId`: 연구 종류를 식별하는 고정 ID. 출시 후 다른 효과를 위해 재사용하지 않는다.
- `presentation`: 텍스트 키, 아이콘, 수치 표시 방식. 표시 정보는 전투 계산에 참여하지 않는다.
- `gameplay.kind`: 커서 스탯, 스킬 해금·스탯, 몬스터 해금·생산량, 일반 필드 시간을 구분한다. 스킬과 몬스터는 `targetId`, 스킬 강화는 `statId`로 대상을 지정한다.
- `gameplay.ranks`: 각 랭크 구매 시 **추가되는 효과**. 예를 들어 `3, 3, 3`이면 3랭크의 누적 효과는 9다. 배열 길이가 최대 랭크이며 0랭크의 연구 효과는 없다. 몬스터 생성량·필드 시간은 `baselineValue`에 각 랭크 증가량을 더해 목표값을 구한다. 호환용 비용 필드는 이전 씬용이며 맵 배치 비용과 별개다.

연구 맵 에디터로 적용한 배치는 SO에 남아 있는 기존 비용 대신 배치별 비용을 사용한다. 아직 변환하지 않은 씬을 위해 SO 비용은 호환용으로 남아 있다. 에디터 사용법은 `Maps/사용 안내.md`를 참고한다.

효과의 저장 단위는 공격력 정수, 범위 월드 단위, 간격 초, 치명타 확률 퍼센트 포인트, 치명타·보스 피해 배율의 가산분이다. 간격 감소는 음수로 적는다. `presentation.valueDisplay`는 실제 수치를 바꾸지 않고 표시에만 사용한다. 퍼센트는 소수 둘째 자리까지 표시한다. 예를 들어 보스 피해 `0.01`은 전투 배율에 `+0.01`을 더하며 툴팁에는 `1.00%`로 표시한다.

현재 맵은 Main 씬의 `ResearchPrototype_Canvas` 아래 `ResearchTestNode` 배치와 `ResearchTestMap.nodes` 목록을 기준으로 한다. 각 배치의 `placementId`는 같은 SO를 여러 번 사용할 때도 **서로 달라야** 하며, 플레이어의 구매 랭크는 이 ID로 저장된다. 위치를 옮길 때 ID를 바꾸지 않고, 삭제한 ID를 다른 노드에 재사용하지 않는다. `prerequisites`와 `requiredPrerequisites`는 각 배치에서 설정한다. 잘못된 비용, 중복 ID, 누락된 선행 노드 및 순환 연결은 구매 또는 전투 시작 전에 거부한다.

같은 SO를 참조하는 여러 배치는 각자의 저장 랭크에 따른 누적 기여량을 합산한다. 구 연구 구매 내역은 저장에 보관되지만 Main의 새 연구 전투 계산에는 사용하지 않는다. 연구 이외의 보유 특성·유물은 기존 경로를 유지한다. 연구 계산은 전투 시작 시 스냅샷으로 확정된다.

맵 에디터에서 스킬 해금·강화, 몬스터 해금·생산량, 일반 필드 시간도 배치할 수 있다. 스킬 강화와 기본 몬스터를 제외한 몬스터 생산량은 대상 해금 연구가 필수 선행 조건이어야 한다. 해금·생산량·필드 시간 연구는 같은 대상에 중복 배치할 수 없다. SO와 배치 ID의 변경·삭제에 대한 일반 저장 마이그레이션 도구는 별도로 설계해야 한다.

## 전체 노드 테스트

`Maps/ResearchMap_AllNodes_Test.asset`은 연구 50종을 각각 한 번 배치한 테스트 버전이다. 연구 맵 에디터에서 `v2 전체 노드 테스트`를 선택하고 **저장**하면 Main 씬에 적용된다. 모든 테스트 비용은 가넷 0으로 설정되어 보유 재화를 차감하지 않는다. 테스트 배치 ID는 `research-test.`로 시작해 기존 맵의 구매 기록과 구분된다.

테스트 맵으로 전환할 때 기존 씬 노드와 연결선은 비활성 보관 영역에 유지된다. 기존 맵의 현재 상태를 복구할 버전이 없다면 자동 보관 버전을 만든다. 테스트 후에는 에디터에서 기존 버전 또는 자동 보관 버전을 선택하고 저장해 복원한다. 두 맵의 구매 기록은 삭제하지 않으며, 적용된 맵의 배치만 효과를 낸다.

## 연구 텍스트

`Assets/CursorHunter/Data/Authoring/ResearchText.xlsx`의 `연구 표시 정보` 시트가 연구 제목, 효과 설명과 비용·무료·최대 강화 문구의 원본이다. 첫 열은 고정 키, 나머지 열은 `ko`, `en`, `ja` 같은 언어 코드다. SO의 `presentation.textKey`에 접두사를 지정하면 `.title`과 `.description` 행을 사용한다. 한국어는 필수이며 다른 언어는 비워 둘 수 있다. 빈 번역은 한국어로 대체된다.

엑셀을 저장하면 Unity 편집 모드에서 자동으로 Unity Localization의 `Research` 문자열 테이블을 갱신한다. 실행 중 수정한 내용은 편집 모드로 돌아왔을 때 적용된다. `Tools > Cursor Hunter > Research Text > Open Excel / Apply Excel` 메뉴도 사용할 수 있다. 생성된 테이블을 직접 수정하지 않고 항상 엑셀을 수정한다. 빌드 전에는 엑셀을 다시 검사하고, 중복 키·필수 문구 누락·SO 키 누락이 있으면 빌드를 중단한다. 배포된 게임은 빌드된 테이블을 사용하므로 수정 후 다시 빌드해야 한다.
